# M7 — Release & Updates Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Coverly ROMs releasable and self-updating — one version source, a CHANGELOG, a signed multi-OS release pipeline, an in-app updater (stable/beta) that never interrupts a fill job, `coverly update check|install` with minisign verification, plus the open hardening minors — everything that does **not** need the owner (Miguel).

**Architecture:** The Cargo workspace version is the only version (tauri.conf.json has none; `package.json` is kept equal by `scripts/bump-version.sh`). The updater public key lives in exactly one committed file, `crates/coverly-core/updater.pub` (placeholder `UNSET` until the owner commits the real key); the core reads it and offers manifest parsing, SemVer comparison and minisign verification (Tauri's scheme: base64 of the minisign text, `version:` bound in the trusted comment). The CLI uses the core end to end; the app drives `tauri-plugin-updater` **from Rust** (no JS updater permission) behind a small `UpdateDriver` trait so the policy (startup gating, job gating, phases) is unit-tested with a fake. The release workflow builds with tauri-action v1 using a throwaway key and re-signs every update artifact with the real key in a finalize job that builds nothing, adding `cli-<os>-<arch>` entries to the same `latest.json`.

**Tech Stack:** Rust (coverly-core, coverly-cli, Tauri 2.12 shell), `tauri-plugin-updater` ~2.14, `minisign-verify` 0.2, `base64` 0.22, `semver` 1, `minisign` 0.9 (test-util only), React 19 + zustand + Vitest/Testing Library, GitHub Actions (tauri-action v1), Python 3 stdlib release tool, actionlint.

**Spec:** `docs/superpowers/specs/2026-10-15-coverly-roms-design.md` (§4 CLI `coverly update check|install`, §9 General, §11 security, §12 testing, §13 release & updates, §15 M7, §16.11 updater pins; §16 wins on conflict). Decisions: `docs/TRACKER.md` D1–D36 (this plan adds D37–D41). ADR-0008 (`docs/adr/0008-updater-public-releases.md`).

## Review Focus

1. **Replayed manifest** — a `latest.json` that pairs a newer `version` with an older release's genuinely signed artifact must be refused (signed version ≠ announced), not installed as a "downgrade-by-relabel". Pinned in Task 4 (`refuses_a_signature_bound_to_another_version`) and Task 5 (`install_refuses_a_replayed_signature`).
2. **Startup check failing offline** — the startup check must stay silent (no error banner, status back to idle) while a manual check shows the error. Pinned in Task 7 (`startup offline is silent`) and Task 8 (`no banner when the startup check fails`).
3. **A fill job starting after the update was downloaded** — install waits for the job, and "Restart now" is disabled while a job runs (never kills a job). Pinned in Task 6 (`install_and_restart_wait_for_the_job`) and Task 8 (`restart is disabled while a fill job runs`).
4. **Hostile / incomplete manifest** — non-JSON, > 1 MiB, missing this platform's key, or a non-SemVer version must give "no update for this platform" / "manifest not valid", never a crash or a false "up to date". Pinned in Task 4 (`hostile_manifests_are_refused_cleanly`) and Task 5 (`check_without_this_platform_says_so`).
5. **CLI self-replace failing half-way** — if the executable's folder is not writable the old binary must stay intact and runnable, and no temp file is left behind. Pinned in Task 5 (`install_keeps_the_old_binary_when_the_folder_is_read_only`, unix).

```rust
//! Release invariants (M7): one version source, the bump script, and (Task 10)
//! the release workflows and their Python helper.

use std::path::{Path, PathBuf};
use std::process::Command;

fn repo() -> PathBuf {
    Path::new(env!("CARGO_MANIFEST_DIR")).parent().unwrap().to_path_buf()
}

fn read(rel: &str) -> String {
    std::fs::read_to_string(repo().join(rel)).unwrap_or_else(|e| panic!("{rel}: {e}"))
}

fn workspace_version(cargo_toml: &str) -> String {
    let v: toml::Value = toml::from_str(cargo_toml).unwrap();
    v["workspace"]["package"]["version"].as_str().unwrap().to_string()
}

fn lock_version(lock: &str, name: &str) -> Option<String> {
    let v: toml::Value = toml::from_str(lock).unwrap();
    v["package"].as_array()?.iter().find_map(|p| {
        (p["name"].as_str() == Some(name)).then(|| p["version"].as_str().unwrap().to_string())
    })
}

#[test]
fn version_sources_agree() {
    let ws = workspace_version(&read("Cargo.toml"));
    assert_eq!(ws, env!("CARGO_PKG_VERSION"), "src-tauri inherits the workspace version");

        conf.get("version").is_none(),
```

- [ ] **Step 3: Write `scripts/bump-version.sh`** (adapted from Pluryprint's `scripts/bump-version.sh`; `chmod +x`)

```bash
#!/usr/bin/env bash
#
# Set or check the version of Coverly ROMs: scripts/bump-version.sh X.Y.Z[-pre.N]
#
# The root Cargo.toml [workspace.package] version is the only version the
# programs read: coverly-core, coverly-cli and the app inherit it, and
# tauri.conf.json has no `version`, so the bundles, the updater and
# CARGO_PKG_VERSION agree by construction. package.json is kept equal for the
# frontend and the release guard, and Cargo.lock's own entries are patched in
# the same commit so the next cargo command does not dirty the tree.
#
# A version with a pre-release suffix (0.2.0-beta.1) is published to the beta
# channel; one without is stable. .github/workflows/release.yml refuses a tag
# that differs from what this script wrote. See RELEASING.md.
#
# Options:
#   --root DIR   operate on another checkout (tests)
#   --check      print every source and exit 1 when they disagree
#
# It does not commit or tag; it prints the commands to do so.

set -euo pipefail

root="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
check=0
version=""
while [[ $# -gt 0 ]]; do
  case "$1" in
    --root) shift; root="$(cd "${1:?--root needs a directory}" && pwd)" ;;
    --check) check=1 ;;
    -h|--help) sed -n '2,22p' "$0"; exit 0 ;;
    -*) echo "unknown option: $1" >&2; exit 2 ;;
    *) version="$1" ;;
  esac
  shift
done

cargo_toml="$root/Cargo.toml"
cargo_lock="$root/Cargo.lock"
package_json="$root/package.json"
for f in "$cargo_toml" "$cargo_lock" "$package_json"; do
  [[ -f "$f" ]] || { echo "missing $f" >&2; exit 1; }
done

current_versions() {
  python3 -I - "$cargo_toml" "$package_json" "$cargo_lock" <<'PY'
import json, re, sys
cargo, pkg, lock = sys.argv[1:]
text = open(cargo, encoding="utf-8").read()
m = re.search(r'(?ms)^\[workspace\.package\].*?^version = "([^"]+)"', text)
print("Cargo.toml", m.group(1) if m else "<none>")
print("package.json", json.load(open(pkg, encoding="utf-8")).get("version", "<none>"))
lock_text = open(lock, encoding="utf-8").read()
for name in ("coverly-core", "coverly-cli", "coverly-roms"):
    m = re.search(r'name = "%s"\nversion = "([^"]+)"' % re.escape(name), lock_text)
    print("Cargo.lock:" + name, m.group(1) if m else "<none>")
PY
}

if [[ $check -eq 1 ]]; then
  out="$(current_versions)"
  echo "$out"
  if [[ "$(echo "$out" | awk '{print $2}' | sort -u | wc -l | tr -d ' ')" != "1" ]]; then
    echo "versions disagree; run scripts/bump-version.sh X.Y.Z" >&2
    exit 1
  fi
  exit 0
fi

# SemVer 2.0, no leading "v", no build metadata (a tag is v<version>).
semver='^(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)(-[0-9A-Za-z-]+(\.[0-9A-Za-z-]+)*)?$'
if [[ ! "$version" =~ $semver ]]; then
  echo "usage: $0 X.Y.Z[-pre.N]   ('${version}' is not a SemVer version without a leading v)" >&2
  exit 2
fi

python3 -I - "$version" "$cargo_toml" "$package_json" "$cargo_lock" <<'PY'
import json, re, sys
version, cargo, pkg, lock = sys.argv[1:]
text = open(cargo, encoding="utf-8").read()
new, n = re.subn(r'(?ms)(^\[workspace\.package\].*?^version = ")[^"]+(")', r'\g<1>' + version + r'\g<2>', text, count=1)
if n != 1:
    sys.exit("no [workspace.package] version in Cargo.toml")
open(cargo, "w", encoding="utf-8").write(new)
data = json.load(open(pkg, encoding="utf-8"))
data["version"] = version
with open(pkg, "w", encoding="utf-8") as f:
    json.dump(data, f, indent=2, ensure_ascii=False)
    f.write("\n")
lock_text = open(lock, encoding="utf-8").read()
for name in ("coverly-core", "coverly-cli", "coverly-roms"):
    lock_text, n = re.subn(r'(name = "%s"\nversion = ")[^"]+(")' % re.escape(name), r'\g<1>' + version + r'\g<2>', lock_text)
    if n != 1:
        sys.exit(f"no {name} entry in Cargo.lock")
open(lock, "w", encoding="utf-8").write(lock_text)
PY

echo "Version set to $version. Next:"
echo "  move CHANGELOG.md's [Unreleased] notes under ## [$version] - $(date +%Y-%m-%d)"
echo "  git commit -am \"chore(release): $version\" && git tag v$version"
```

Note: `json.dump(..., indent=2)` must reproduce the current `package.json` formatting (2-space indent, trailing newline). Run `pnpm prettier --check package.json` after a scratch bump to confirm; if Prettier disagrees, keep the script's output identical to Prettier's (it is for this file shape).

```rust
/// Why [`read_settings_checked`] fell back to the defaults.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum ReadProblem {
    /// Not JSON settings (garbage, too large, not UTF-8, not an object).
    NotSettings,
    /// A folder, or no permission.
    Unreadable,
}

/// Like [`read_settings`], also saying why the defaults were used. Never
/// touches the disk; a missing file is not a problem.
pub fn read_settings_checked(path: &Path, known: &[String]) -> (Settings, Option<ReadProblem>) {
    match read_capped(path) {
        Read_::Missing => (Settings::default(), None),
        Read_::Unreadable => (Settings::default(), Some(ReadProblem::Unreadable)),
        Read_::TooLarge => (Settings::default(), Some(ReadProblem::NotSettings)),
        Read_::Text(text) => match parse_tolerant(&text, known) {
            Some(p) => (p.settings, None),
            None => (Settings::default(), Some(ReadProblem::NotSettings)),
        },
    }
}

/// Like [`load_settings`] without touching the disk (the CLI).
pub fn read_settings(path: &Path, known: &[String]) -> Settings {
    read_settings_checked(path, known).0
}
```

```rust
//! minisign verification in Tauri's format: the public key and the signature
//! are base64 of minisign's own text; the trusted comment carries
//! `version:<v>` (written by `tauri signer sign --app-version`), which must
//! equal the version the manifest announces (`requireSignedVersion`).

use base64::Engine as _;
use minisign_verify::{PublicKey, Signature};

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum VerifyError {
    #[error("the update key is not a minisign public key")]
    BadKey,
    #[error("the signature does not match the file")]
    BadSignature,
    #[error("the signature is not bound to a version")]
    MissingVersion,
    #[error("the file was signed for {signed}, but the manifest announces {announced}")]
    VersionMismatch { signed: String, announced: String },
}

fn decode_text(b64: &str) -> Option<String> {
    let bytes = base64::engine::general_purpose::STANDARD.decode(b64.trim()).ok()?;
    String::from_utf8(bytes).ok()
}

/// The `version:` field of a trusted comment (`timestamp:…\tfile:…\tversion:1.2.3`).
pub fn signed_version(trusted_comment: &str) -> Option<&str> {
    trusted_comment.split('\t').find_map(|f| f.strip_prefix("version:"))
}

fn bare(v: &str) -> &str {
    v.trim().trim_start_matches(['v', 'V'])
}

/// Verifies `data` against `signature_b64` with `pubkey_b64`, then (only
/// after the signature checked out, so the comment is trusted) that it was
/// signed for `announced_version`.
pub fn verify_signed(
    data: &[u8],
    signature_b64: &str,
    pubkey_b64: &str,
    announced_version: &str,
) -> Result<(), VerifyError> {
    let pk_text = decode_text(pubkey_b64).ok_or(VerifyError::BadKey)?;
    let pk = PublicKey::decode(&pk_text).map_err(|_| VerifyError::BadKey)?;
    let sig_text = decode_text(signature_b64).ok_or(VerifyError::BadSignature)?;
    let sig = Signature::decode(&sig_text).map_err(|_| VerifyError::BadSignature)?;
    pk.verify(data, &sig, true).map_err(|_| VerifyError::BadSignature)?;
    match signed_version(sig.trusted_comment()) {
        None => Err(VerifyError::MissingVersion),
        Some(v) if bare(v) == bare(announced_version) => Ok(()),
        Some(v) => Err(VerifyError::VersionMismatch {
            signed: bare(v).to_string(),
            announced: bare(announced_version).to_string(),
        }),
    }
}
```

```rust
//! committed public key, the manifest itself, SemVer, and a verified

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum UpdateError {
    #[error("offline or unreachable: {0}")]
    Offline(String),
    #[error("no update is published at {0}")]
    NotPublished(String),
    #[error("the update manifest is not valid: {0}")]
    BadManifest(String),
    #[error("no update for this platform ({0})")]
    NoPlatform(String),
    #[error("the download failed its signature check and was NOT installed: {0}")]
    Signature(String),
    #[error("this build has no update key, so it cannot update itself; download new versions from the releases page")]
    NoKey,
    #[error("{0}")]
    Network(String),
}

impl From<NetError> for UpdateError {
    fn from(e: NetError) -> Self {
        match e {
            NetError::Offline(_) | NetError::Timeout => UpdateError::Offline(e.to_string()),
            NetError::TooLarge { .. } => UpdateError::BadManifest(e.to_string()),
            other => UpdateError::Network(other.to_string()),
        }
    }
}

pub fn endpoint_for(channel: UpdateChannel) -> &'static str {
    match channel {
        UpdateChannel::Stable => STABLE_ENDPOINT,
        UpdateChannel::Beta => BETA_ENDPOINT,
    }
}

/// The override when set and non-blank (http or https), else the channel's.
pub fn resolve_endpoint(
    override_value: Option<&str>,
    channel: UpdateChannel,
) -> Result<String, UpdateError> {
    match override_value.map(str::trim).filter(|v| !v.is_empty()) {
        None => Ok(endpoint_for(channel).to_string()),
        Some(v) if (v.starts_with("https://") || v.starts_with("http://")) && !v.contains(char::is_whitespace) => {
            Ok(v.to_string())
        }
        Some(v) => Err(UpdateError::Network(format!("invalid update endpoint {v:?}"))),
    }
}

/// The first line that is not blank or a `#` comment, unless it is the placeholder.
pub fn parse_pubkey_file(text: &str) -> Option<&str> {

        .find(|l| !l.is_empty() && !l.starts_with('#'))
        .filter(|l| *l != PUBKEY_PLACEHOLDER)

pub fn release_pubkey() -> Option<&'static str> {

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct PlatformEntry {
    pub url: String,
    pub signature: String,

/// `latest.json` as tauri-action writes it, plus our `cli-<os>-<arch>` keys.
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct Manifest {
    pub version: String,
    #[serde(default)]
    pub notes: Option<String>,
    #[serde(default)]
    pub pub_date: Option<String>,
    #[serde(default)]
    pub platforms: BTreeMap<String, PlatformEntry>,
}

fn parse_version(v: &str) -> Option<semver::Version> {
    semver::Version::parse(v.trim().trim_start_matches(['v', 'V'])).ok()
}

pub fn parse_manifest(bytes: &[u8]) -> Result<Manifest, UpdateError> {
    let m: Manifest =
        serde_json::from_slice(bytes).map_err(|e| UpdateError::BadManifest(e.to_string()))?;
    if parse_version(&m.version).is_none() {
        return Err(UpdateError::BadManifest(format!("{:?} is not a version", m.version)));
    }
    Ok(m)
}

/// SemVer precedence (build metadata ignored); unparseable is never newer.
pub fn is_newer(current: &str, candidate: &str) -> bool {
    match (parse_version(current), parse_version(candidate)) {
        (Some(cur), Some(new)) => new.cmp_precedence(&cur).is_gt(),
        _ => false,
    }
}

pub fn cli_platform_key_for(os: &str, arch: &str) -> Option<String> {
    let os = match os {
        "macos" => "darwin",
        "windows" => "windows",
        "linux" => "linux",
        _ => return None,
    };
    matches!(arch, "x86_64" | "aarch64").then(|| format!("cli-{os}-{arch}"))
}

pub fn cli_platform_key() -> Option<String> {
    cli_platform_key_for(std::env::consts::OS, std::env::consts::ARCH)
}

#[derive(Clone, Debug, PartialEq)]
pub enum Check {
    UpToDate { latest: String },
    Available(Manifest),
}

fn get(http: &dyn Http, url: &str, cap: u64) -> Result<Vec<u8>, UpdateError> {
    let resp = http.get(&HttpRequest::get(url).max_bytes(cap))?;
    match resp.status {
        200..=299 => Ok(resp.body),
        404 => Err(UpdateError::NotPublished(url.to_string())),
        s => Err(UpdateError::Network(format!("HTTP {s} for {url}"))),
    }
}

/// Reads the manifest at `url` (one request) and compares it with `current`.
pub fn check(http: &dyn Http, url: &str, current: &str) -> Result<Check, UpdateError> {
    let m = parse_manifest(&get(http, url, MAX_MANIFEST_BYTES)?)?;
    Ok(if is_newer(current, &m.version) {
        Check::Available(m)
    } else {
        Check::UpToDate { latest: m.version }
    })
}

/// Downloads `platform_key`'s file and returns it only when its signature
/// verifies with `pubkey` and is bound to `manifest.version`.
pub fn download_verified(
    http: &dyn Http,
    manifest: &Manifest,
    platform_key: &str,
    pubkey: &str,
) -> Result<Vec<u8>, UpdateError> {
    let entry = manifest
        .platforms
        .get(platform_key)
        .ok_or_else(|| UpdateError::NoPlatform(platform_key.to_string()))?;
    let bytes = get(http, &entry.url, MAX_ARTIFACT_BYTES)?;
    verify::verify_signed(&bytes, &entry.signature, pubkey, &manifest.version)
        .map_err(|e| UpdateError::Signature(e.to_string()))?;
    Ok(bytes)
}
```

```rust
//! release build (the `minisign` crate is only in the `test-util` feature).

use base64::Engine as _;

pub struct TestKey {
    pk: minisign::PublicKey,
    sk: minisign::SecretKey,
}

fn b64(text: &str) -> String {
    base64::engine::general_purpose::STANDARD.encode(text.as_bytes())
}

impl TestKey {
    pub fn generate() -> TestKey {
        let minisign::KeyPair { pk, sk } =
            minisign::KeyPair::generate_unencrypted_keypair().expect("keypair");
        TestKey { pk, sk }
    }

    /// What `tauri signer generate` prints as the public key.
    pub fn public_b64(&self) -> String {
        b64(&self.pk.to_box().expect("pk box").to_string())
    }

    /// What `tauri signer sign [--app-version V]` writes to the `.sig` file.
    pub fn sign(&self, data: &[u8], file_name: &str, version: Option<&str>) -> String {
        let mut trusted = format!("timestamp:1700000000\tfile:{file_name}");
        if let Some(v) = version {
            trusted.push_str(&format!("\tversion:{v}"));
        }
        let sig = minisign::sign(
            Some(&self.pk),
            &self.sk,
            std::io::Cursor::new(data),
            Some(&trusted),
            Some("signature from tauri secret key"),
        )
        .expect("sign");
        b64(&sig.to_string())
    }
}

/// A `latest.json` with `entries` = `(platform key, url, signature)`.

        .iter()

        .collect();
    serde_json::json!({
        "version": version,
        "notes": "Test notes",
        "pub_date": "2026-10-16T00:00:00Z",
        "platforms": platforms,
    })
    .to_string()
}
```

```rust
//! `coverly update check|install` (spec §4, M7): the same manifest as the
//! app, a minisign-verified download, and an atomic self-replace.

use std::fs;
use std::io::{self, Write};
use std::path::Path;

use clap::{Args, Subcommand, ValueEnum};
use coverly_core::net::UreqHttp;
use coverly_core::settings::UpdateChannel;

pub const PUBKEY_ENV: &str = "COVERLY_UPDATE_PUBKEY";

pub struct UpdateArgs {

#[derive(Debug, Subcommand)]
pub enum UpdateAction {
    /// Say whether a newer version is published (reads the manifest only).
    Check(CommonArgs),
    /// Download, verify and install the newest version of this binary.
    Install(InstallArgs),
}

#[derive(Debug, Clone, Copy, ValueEnum)]

    Stable,
    Beta,

#[derive(Debug, Args)]
pub struct CommonArgs {

    #[arg(long, value_enum)]
    pub channel: Option<ChannelArg>,
    /// Print JSON.
    #[arg(long)]
    pub json: bool,
}

fn failure(e: UpdateError) -> Failure {
    let code = match e {
        UpdateError::Signature(_) | UpdateError::NoKey => 6,
        _ => 1,
    };
    Failure { code, message: e.to_string() }
}

fn pubkey() -> Option<String> {
    if cfg!(debug_assertions) {
        if let Some(k) = std::env::var(PUBKEY_ENV).ok().filter(|k| !k.trim().is_empty()) {
            return Some(k.trim().to_string());
        }
    }
    coverly_core::update::release_pubkey().map(str::to_string)
}

pub fn run(args: &UpdateArgs) -> Result<(), Failure> {
    let cli = crate::settings::load_cli_settings();
    let common = match &args.action {
        UpdateAction::Check(c) => c,
        UpdateAction::Install(i) => &i.common,
    };
    let channel = match common.channel {
        Some(ChannelArg::Stable) => UpdateChannel::Stable,
        Some(ChannelArg::Beta) => UpdateChannel::Beta,
        None => cli.settings.general.update_channel,
    };
    let url = resolve_endpoint(std::env::var(ENDPOINT_ENV).ok().as_deref(), channel)
        .map_err(failure)?;
    let http = UreqHttp::new(&cli.settings.net_config());
    let outcome = check(&http, &url, CURRENT).map_err(failure)?;
    match (&args.action, outcome) {
        (UpdateAction::Check(c), outcome) => report(c.json, &outcome),
        (UpdateAction::Install(_), Check::UpToDate { latest }) => {
            print_stdout(&format!("coverly is up to date ({CURRENT}; latest {latest}).\n"))
        }
        (UpdateAction::Install(i), Check::Available(m)) => {
            let key = pubkey().ok_or_else(|| failure(UpdateError::NoKey))?;
            let platform = cli_platform_key()
                .ok_or_else(|| failure(UpdateError::NoPlatform(std::env::consts::OS.into())))?;
            let bytes = download_verified(&http, &m, &platform, &key).map_err(failure)?;
            if i.dry_run {
                return print_stdout(&format!(
                    "{} {} verified ({} bytes); not installed (dry run).\n",
                    platform, m.version, bytes.len()
                ));
            }
            let exe = std::env::current_exe()?;
            replace_executable(&exe, &bytes).map_err(|e| Failure {
                code: 1,
                message: format!("could not replace {}: {e}; the current binary is unchanged", exe.display()),
            })?;
            print_stdout(&format!("Updated to {} (was {CURRENT}).\n", m.version))
        }
    }
}

fn report(json: bool, outcome: &Check) -> Result<(), Failure> {
    let (latest, available, notes) = match outcome {
        Check::UpToDate { latest } => (latest.clone(), false, None),
        Check::Available(m) => (m.version.clone(), true, m.notes.clone()),
    };
    if json {
        let v = serde_json::json!({ "current": CURRENT, "latest": latest, "available": available, "notes": notes });
        return print_stdout(&format!("{v}\n"));
    }
    if available {
        print_stdout(&format!(
            "coverly {latest} is available (you have {CURRENT}). Run `coverly update install`.\n"
        ))
    } else {
        print_stdout(&format!("coverly is up to date ({CURRENT}).\n"))
    }
}

/// Writes `bytes` next to `exe` and renames it over `exe` (Windows: moves the
/// running file aside first). On failure `exe` is unchanged and no temp file is left.
pub fn replace_executable(exe: &Path, bytes: &[u8]) -> io::Result<()> {
    let dir = exe.parent().ok_or_else(|| io::Error::other("no parent folder"))?;
    let name = exe.file_name().ok_or_else(|| io::Error::other("no file name"))?.to_string_lossy();
    let tmp = dir.join(format!(".{name}.new-{}", std::process::id()));
    let result = (|| {
        let mut f = fs::File::create(&tmp)?;
        f.write_all(bytes)?;
        f.sync_all()?;
        drop(f);
        #[cfg(unix)]
        {
            use std::os::unix::fs::PermissionsExt;
            fs::set_permissions(&tmp, fs::Permissions::from_mode(0o755))?;
        }
        #[cfg(windows)]
        {
            let old = exe.with_extension("old.exe");
            let _ = fs::remove_file(&old);
            fs::rename(exe, &old)?;
            if let Err(e) = fs::rename(&tmp, exe) {
                let _ = fs::rename(&old, exe);
                return Err(e);
            }
            Ok(())
        }
        #[cfg(not(windows))]
        fs::rename(&tmp, exe)
    })();
    if result.is_err() {
        let _ = fs::remove_file(&tmp);
    }
    result
}
```

```rust
//! In-app updates (M7, ADR-0011): the policy lives here and is tested with a
//! fake driver; `PluginDriver` is the thin `tauri-plugin-updater` binding.
//! The webview never talks to the plugin (no `updater:` permission): it calls
//! these commands, and the endpoint and key are always ours.

use std::sync::Mutex;

use coverly_core::settings::GeneralSettings;
use serde::{Deserialize, Serialize};

use crate::error::IpcError;

/// `plugins.updater.pubkey` in tauri.conf.json; the real key is set at runtime.
pub const CONF_PUBKEY_MARKER: &str = "set at runtime from crates/coverly-core/updater.pub";

#[derive(Clone, Copy, Debug, PartialEq, Eq, Deserialize, Serialize)]
#[serde(rename_all = "kebab-case")]
pub enum CheckTrigger {
    Startup,
    Manual,
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize)]
pub struct UpdateOfferView {
    pub version: String,
    pub notes: Option<String>,
    pub date: Option<String>,
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize)]
#[serde(tag = "kind", rename_all = "kebab-case")]
pub enum UpdateCheckView {
    /// Startup check with "check on start" off: nothing was requested.
    Skipped,
    UpToDate { current: String, latest: String },
    Available { current: String, offer: UpdateOfferView },
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize)]
pub struct UpdateProgressEvent {
    pub downloaded: u64,
    pub total: Option<u64>,
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize)]
pub struct UpdateInstallView {
    /// macOS/Linux: the new version runs after a restart. Windows never gets
    /// here (the installer ends this process).
    pub restart_required: bool,
}

pub trait UpdateDriver: Send + Sync {
    fn check(&self, endpoint: &str, pubkey: &str) -> Result<Option<UpdateOfferView>, IpcError>;
    fn download(&self, on_progress: &mut dyn FnMut(u64, Option<u64>)) -> Result<(), IpcError>;
    fn install(&self) -> Result<UpdateInstallView, IpcError>;
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
enum Phase {
    Idle,
    Available,
    Downloading,
    Downloaded,
    Installed,
}

pub struct UpdateManager {
    driver: Box<dyn UpdateDriver>,
    pubkey: Option<String>,
    endpoint_override: Option<String>,
    phase: Mutex<Phase>,
}

impl UpdateManager {
    pub fn new(driver: Box<dyn UpdateDriver>, pubkey: Option<String>, endpoint_override: Option<String>) -> Self {
        UpdateManager { driver, pubkey, endpoint_override, phase: Mutex::new(Phase::Idle) }
    }

    fn phase(&self) -> std::sync::MutexGuard<'_, Phase> {
        self.phase.lock().unwrap_or_else(|e| e.into_inner())
    }

    pub fn check(&self, trigger: CheckTrigger, general: &GeneralSettings, current: &str) -> Result<UpdateCheckView, IpcError> {
        if trigger == CheckTrigger::Startup && !general.check_updates_on_launch {
            return Ok(UpdateCheckView::Skipped);
        }
        let pubkey = self.pubkey.as_deref().ok_or(IpcError::UpdateNoKey)?;
        if matches!(*self.phase(), Phase::Downloading | Phase::Downloaded | Phase::Installed) {
            // An update is already on its way: a new check would drop it.
            return Err(IpcError::UpdateFailed("an update is already being installed".into()));
        }
        let endpoint = coverly_core::update::resolve_endpoint(self.endpoint_override.as_deref(), general.update_channel)
            .map_err(|e| IpcError::UpdateFailed(e.to_string()))?;
        let found = self.driver.check(&endpoint, pubkey)?;
        *self.phase() = if found.is_some() { Phase::Available } else { Phase::Idle };
        Ok(match found {
            Some(offer) => UpdateCheckView::Available { current: current.to_string(), offer },
            None => UpdateCheckView::UpToDate { current: current.to_string(), latest: current.to_string() },
        })
    }

    pub fn download(&self, on_progress: &mut dyn FnMut(u64, Option<u64>)) -> Result<(), IpcError> {
        {
            let mut p = self.phase();
            if *p != Phase::Available {
                return Err(IpcError::UpdateNotReady);
            }
            *p = Phase::Downloading;
        }
        let result = self.driver.download(on_progress);
        *self.phase() = if result.is_ok() { Phase::Downloaded } else { Phase::Idle };
        result
    }

    pub fn install(&self, job_running: bool) -> Result<UpdateInstallView, IpcError> {
        if *self.phase() != Phase::Downloaded {
            return Err(IpcError::UpdateNotReady);
        }
        if job_running {
            return Err(IpcError::JobRunning);
        }
        let view = self.driver.install()?;
        *self.phase() = Phase::Installed;
        Ok(view)
    }

    pub fn can_restart(&self, job_running: bool) -> Result<(), IpcError> {
        if *self.phase() != Phase::Installed {
            return Err(IpcError::UpdateNotReady);
        }
        if job_running {
            return Err(IpcError::JobRunning);
        }
        Ok(())
    }
}

/// Every way the plugin can fail, in the IPC vocabulary.
pub fn classify(err: &tauri_plugin_updater::Error) -> IpcError {
    use tauri_plugin_updater::Error as E;
    match err {
        E::Minisign(_) | E::Base64(_) | E::SignatureUtf8(_) | E::SignedVersionMismatch { .. } | E::MissingSignedVersion => {
            IpcError::UpdateSignature(err.to_string())
        }
        E::Reqwest(_) | E::Network(_) => IpcError::UpdateOffline(err.to_string()),
        E::ReleaseNotFound | E::Serialization(_) | E::TargetNotFound(_) | E::TargetsNotFound(_) => {
            IpcError::UpdateUnavailable(err.to_string())
        }
        other => IpcError::UpdateFailed(other.to_string()),
    }
}

/// The real driver: `tauri-plugin-updater`, blocking on its futures from the
/// blocking pool (the IPC commands already run there).
pub struct PluginDriver<R: tauri::Runtime> {
    app: tauri::AppHandle<R>,
    pending: Mutex<Option<tauri_plugin_updater::Update>>,
    bytes: Mutex<Option<Vec<u8>>>,
}

impl<R: tauri::Runtime> PluginDriver<R> {
    pub fn new(app: tauri::AppHandle<R>) -> Self {
        PluginDriver { app, pending: Mutex::new(None), bytes: Mutex::new(None) }
    }
}

impl<R: tauri::Runtime> UpdateDriver for PluginDriver<R> {
    fn check(&self, endpoint: &str, pubkey: &str) -> Result<Option<UpdateOfferView>, IpcError> {
        use tauri_plugin_updater::UpdaterExt;
        let url = tauri::Url::parse(endpoint).map_err(|e| IpcError::UpdateFailed(e.to_string()))?;
        let updater = self
            .app
            .updater_builder()
            .pubkey(pubkey)
            .endpoints(vec![url])
            .and_then(|b| b.build())
            .map_err(|e| classify(&e))?;
        let found = tauri::async_runtime::block_on(updater.check()).map_err(|e| classify(&e))?;
        let view = found.as_ref().map(|u| UpdateOfferView {
            version: u.version.clone(),
            notes: u.body.clone(),
            date: u.raw_json.get("pub_date").and_then(|d| d.as_str()).map(String::from),
        });
        *self.pending.lock().unwrap_or_else(|e| e.into_inner()) = found;
        *self.bytes.lock().unwrap_or_else(|e| e.into_inner()) = None;
        Ok(view)
    }

    fn download(&self, on_progress: &mut dyn FnMut(u64, Option<u64>)) -> Result<(), IpcError> {
        let update = self.pending.lock().unwrap_or_else(|e| e.into_inner()).clone().ok_or(IpcError::UpdateNotReady)?;
        let mut done = 0u64;
        // `download` verifies the signature before returning any byte.
        let bytes = tauri::async_runtime::block_on(update.download(
            |chunk, total| {
                done += chunk as u64;
                on_progress(done, total);
            },
            || {},
        ))
        .map_err(|e| classify(&e))?;
        *self.bytes.lock().unwrap_or_else(|e| e.into_inner()) = Some(bytes);
        Ok(())
    }

    fn install(&self) -> Result<UpdateInstallView, IpcError> {
        let update = self.pending.lock().unwrap_or_else(|e| e.into_inner()).clone().ok_or(IpcError::UpdateNotReady)?;
        let bytes = self.bytes.lock().unwrap_or_else(|e| e.into_inner()).take().ok_or(IpcError::UpdateNotReady)?;
        update.install(bytes).map_err(|e| classify(&e))?;
        Ok(UpdateInstallView { restart_required: !cfg!(windows) })
    }
}
```

```ts
/**
 * The in-app updater as the UI follows it (M7). The startup check runs at
 * most once per page and only when the setting is on (otherwise nothing is
 * requested); its failures are silent. Installing waits for a running fill
 * job, and restarting is refused while one runs.
 */
import { create } from 'zustand';

import { getBackend } from '@/ipc/backend';
import { BackendError, toBackendError } from '@/ipc/errors';
import type { UpdateOffer, UpdateProgress, UpdateTrigger } from '@/ipc/types';

import { isRunning, useJobStore } from './jobStore';

export type UpdateStatus =
  | 'idle' | 'checking' | 'up-to-date' | 'available' | 'downloading'
  | 'waiting-for-job' | 'installing' | 'ready' | 'error';

interface UpdateStore {
  status: UpdateStatus;
  current: string | null;
  offer: UpdateOffer | null;
  progress: UpdateProgress | null;
  error: BackendError | null;
  trigger: UpdateTrigger | null;
  checkedAt: number | null;
  bannerDismissed: boolean;
  startupCheck(enabled: boolean): Promise<void>;
  check(trigger: UpdateTrigger): Promise<void>;
  download(): Promise<void>;
  install(): Promise<void>;
  restart(): Promise<void>;
  dismissBanner(): void;
}

const initial = {
  status: 'idle' as UpdateStatus,
  current: null,
  offer: null,
  progress: null,
  error: null,
  trigger: null,
  checkedAt: null,
  bannerDismissed: false,
};

let startupDone = false;
let waitOff: (() => void) | null = null;

const jobBusy = () => isRunning(useJobStore.getState().job);

export const useUpdateStore = create<UpdateStore>()((set, get) => ({
  ...initial,
  async startupCheck(enabled) {
    if (startupDone) return;
    startupDone = true;
    if (!enabled) return; // no request at all
    await get().check('startup');
  },
  async check(trigger) {
    if (['checking', 'downloading', 'installing', 'waiting-for-job'].includes(get().status)) return;
    set({ status: 'checking', error: null, trigger });
    try {
      const b = await getBackend();
      const r = await b.checkForUpdates(trigger);
      if (r.kind === 'skipped') return set({ status: 'idle' });
      set({
        checkedAt: Date.now(),
        current: r.current,
        offer: r.kind === 'available' ? r.offer : null,
        status: r.kind === 'available' ? 'available' : 'up-to-date',
      });
    } catch (e) {
      if (trigger === 'startup') set({ status: 'idle' });
      else set({ status: 'error', error: toBackendError(e) });
    }
  },
  async download() {
    if (get().status !== 'available') return;
    set({ status: 'downloading', progress: null, error: null });
    const b = await getBackend();
    const off = await b.onUpdateProgress((p) => set({ progress: p }));
    try {
      await b.downloadUpdate();
    } catch (e) {
      off();
      return set({ status: 'error', error: toBackendError(e) });
    }
    off();
    await get().install();
  },
  async install() {
    // Wait for the next job store change that shows no running job.
    const waitForJob = () => {
      set({ status: 'waiting-for-job' });
      waitOff?.();
      waitOff = useJobStore.subscribe((s) => {
        if (isRunning(s.job)) return;
        waitOff?.();
        waitOff = null;
        void get().install();
      });
    };
    if (jobBusy()) return waitForJob();
    set({ status: 'installing' });
    try {
      await (await getBackend()).installUpdate();
      set({ status: 'ready' });
    } catch (e) {
      const err = toBackendError(e);
      // The backend saw a job the store had not heard of yet: wait, never loop.
      if (err.code === 'job-running') return waitForJob();
      set({ status: 'error', error: err });
    }
  },
  async restart() {
    if (get().status !== 'ready' || jobBusy()) return;
    try {
      await (await getBackend()).restartApp();
    } catch (e) {
      set({ error: toBackendError(e) });
    }
  },
  dismissBanner: () => set({ bannerDismissed: true }),
}));

/** Tests only. */
export function resetUpdateStore(): void {
  startupDone = false;
  waitOff?.();
  waitOff = null;
  useUpdateStore.setState({ ...initial });
}
```

```rust
//! Connected drives for the Start screen (spec §8, M3-06). Only lists
//! folders: never opens, writes or mounts anything.

use std::collections::BTreeMap;
use std::path::{Path, PathBuf};

use serde::Serialize;

#[derive(Clone, Debug, PartialEq, Eq, Serialize)]
pub struct Volume {
    pub path: String,
    pub name: String,
}

pub fn mount_parents() -> Vec<PathBuf> {
    if cfg!(target_os = "macos") {
        return vec![PathBuf::from("/Volumes")];
    }
    if cfg!(target_os = "linux") {
        let mut out = Vec::new();
        if let Ok(user) = std::env::var("USER") {
            out.push(Path::new("/media").join(&user));
            out.push(Path::new("/run/media").join(&user));
        }
        out.push(PathBuf::from("/media"));
        return out;
    }
    Vec::new()
}

pub fn list_volumes(parents: &[PathBuf]) -> Vec<Volume> {
    let root = Path::new("/").canonicalize().ok();
    let mut found: BTreeMap<String, Volume> = BTreeMap::new();
    for parent in parents {
        let Ok(entries) = std::fs::read_dir(parent) else { continue };
        for entry in entries.flatten() {
            let name = entry.file_name().to_string_lossy().into_owned();
            if name.starts_with('.') {
                continue;
            }
            let path = entry.path();
            let Ok(real) = path.canonicalize() else { continue };
            if !real.is_dir() || Some(&real) == root.as_ref() {
                continue;
            }
            found.entry(real.display().to_string()).or_insert(Volume { path: path.display().to_string(), name });
        }
    }
    let mut out: Vec<Volume> = found.into_values().collect();
    out.sort_by(|a, b| a.name.to_lowercase().cmp(&b.name.to_lowercase()));
    out
}

pub fn mounted_volumes() -> Vec<Volume> {
    #[cfg(windows)]
    {
        let system = std::env::var("SystemDrive").unwrap_or_else(|_| "C:".into()).to_uppercase();
        return (b'D'..=b'Z')
            .map(|c| format!("{}:\\", c as char))
            .filter(|d| !d.starts_with(&system) && Path::new(d).is_dir())
            .map(|d| Volume { name: d.trim_end_matches('\\').to_string(), path: d })
            .collect();
    }
    #[cfg(not(windows))]
    list_volumes(&mount_parents())
}
```

```rust
/// A job key line: exactly two spaces of indent, then `name:`.
fn is_job_key(line: &str) -> bool {
    line.starts_with("  ")
        && !line.starts_with("   ")
        && line.trim_end().ends_with(':')
        && !line.trim_start().starts_with('#')
}

/// The text of job `name` in a workflow (its key line up to the next job key).
fn job(workflow: &str, name: &str) -> String {
    let key = format!("  {name}:");
    let mut lines = workflow.lines().skip_while(|l| l.trim_end() != key);
    let first = lines.next().unwrap_or_else(|| panic!("no job {name}"));
    let mut out = vec![first];
    out.extend(lines.take_while(|l| !is_job_key(l)));
    out.join("\n")
}
```

```python
def asset_name(url: str) -> str:
    return urllib.parse.unquote(url.rstrip("/").rsplit("/", 1)[-1])


def list_artifacts(manifest: dict) -> list[str]:
    seen = []
    for entry in manifest.get("platforms", {}).values():
        name = asset_name(entry["url"])
        if name not in seen:
            seen.append(name)
    return seen


def resign_manifest(manifest: dict, sigdir: str) -> list[str]:
    errors = []
    for key, entry in manifest.get("platforms", {}).items():
        path = os.path.join(sigdir, asset_name(entry["url"]) + ".sig")
        if not os.path.isfile(path):
            errors.append(f"{key}: no {path}")
            continue
        with open(path, encoding="utf-8") as f:
            entry["signature"] = f.read().strip()
    return errors


CLI_FILE = re.compile(r"coverly-(?P<v>[^-]+(?:-[0-9A-Za-z.-]+)?)-(?P<os>darwin|windows|linux)-(?P<arch>x86_64|aarch64)(?:\.exe)?")


def add_cli(manifest: dict, directory: str, version: str, base_url: str) -> list[str]:
    errors, added = [], 0
    platforms = manifest.setdefault("platforms", {})
    for name in sorted(os.listdir(directory)):
        if name.endswith(".sig"):
            continue
        m = CLI_FILE.fullmatch(name)
        if not m or m.group("v") != version:
            errors.append(f"unexpected file {name}")
            continue
        sig = os.path.join(directory, name + ".sig")
        if not os.path.isfile(sig):
            errors.append(f"{name} has no .sig")
            continue
        with open(sig, encoding="utf-8") as f:
            platforms[f"cli-{m.group('os')}-{m.group('arch')}"] = {
                "url": f"{base_url.rstrip('/')}/{urllib.parse.quote(name)}",
                "signature": f.read().strip(),
            }
        added += 1
    if added == 0:
        errors.append(f"no CLI binaries in {directory}")
    return errors


def read_pubkey(path: str) -> str | None:
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line and not line.startswith("#"):
                return None if line == "UNSET" else line
    return None
```
