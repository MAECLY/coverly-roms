# M6 — Secondary Sources (SteamGridDB, Popularity by votes, ScreenScraper) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Art can come from more than libretro-thumbnails: SteamGridDB (the user's own API key, from the keychain) adds voted portrait covers, the Popularity strategy picks by those votes (D9 a), by cross-source/region consensus when there are no votes (D9 b) and by Priority otherwise, every pick carries a short "why" shown in the review queue and the drawer, and a ScreenScraper client (M6-02, v1.1) is built and fully mock-tested but stays hidden unless the build carries developer credentials. Spec §15 M6 exit: **"Popularity strategy picks by votes"**.

**Architecture:** Two new `ArtSource` implementations in `coverly-core::sources` (`steamgriddb`, `screenscraper`) on the same polite HTTP client, which learns to send a Bearer key (never printed) and to hand a 403 back to an API source instead of pausing. Candidates gain `Votes { up, down }` and a provenance `origin`. `gather` merges the candidates of every enabled source in the user's order (dedupe per source+URL, cross-source consensus, a source whose key is refused is skipped for the rest of the run with one warning). `matching::Popularity` ranks votes → match kind → consensus → source order → region, and `matching::explain` turns the first two of a ranked list into a `PickReason` stored on every plan item. `FillEnv` builds its sources from a `SourceKeys` snapshot (keychain in the app, environment in the CLI), so workers never touch the keychain. `src-tauri` adds `sources_info` and `test_source_key`, and the React app turns the Sources section live, shows source badges, votes and the reason, and explains the strategy in the wizard; the mock backend mirrors it.

**Tech Stack:** Rust 1.90 (edition 2021), `ureq` 3 (rustls), `serde_json`, `percent-encoding`, `rusqlite` cache (all already in the core; **no new crates**), Tauri 2.12, React 19 + TypeScript (strict) + Tailwind 3 + zustand 5, Vitest + Testing Library. ## Deviations from the spec / task brief (decided in this plan)

- **D33 — Popularity order.** Under Popularity every *exact* match kind (canonical, name-exact, title-exact) is one tier, so a voted SteamGridDB grid of the same title can beat libretro's exact file name; fuzzy stays a lower tier. Inside the tier: net votes (up − down, missing = 0) → match kind (canonical > name > title) → consensus → source order → region order (Priority). Without votes this is exactly the M2 behaviour. Priority and RomRegion are unchanged.
- **D34 — Cross-source consensus** (D9 b for consoles): `consensus` = 1 + the source's other media listings carrying the same file (M2) **+ the number of other sources offering the same title (same parsed title key) in an overlapping region**. Measured only when the strategy is Popularity. SteamGridDB grids have no region, so they never add or receive consensus (they compete by votes).
- **D35 — SteamGridDB scope and errors.** Covers only (`/grids`, static, portrait `600x900` then `342x482`; nsfw/humor/epilepsy off); heroes, logos and icons are out of scope. Searched by title for **every** system (SteamGridDB holds many console games; when it has nothing, nothing is lost). An exact title found once → `title-exact` 95; found more than once → `fuzzy` 85 (review). 401/403 → `SourceError::Auth` (that source only, never a pause: spec §10's "403 pauses" stays for libretro/GitHub, which is a rate limit there). The key is read from the keychain once per job into a `SourceKeys` snapshot (with the rest of the settings snapshot), never by worker threads. Images are fetched from the CDN **without** the key.
- **D36 — ScreenScraper.** API v2 (`api.screenscraper.fr/api2`, `jeuInfos.php` by crc+md5+sha1+size+file name+system, `jeuRecherche.php` by title when not hashed). Media: cover → `box-2D` (`flyer` for arcade), screenshot → `ss`, title → `sstitle`, one candidate per region. Candidate URLs are built by Coverly (`mediaJeu.php?systemeid&jeuid&media`) **without credentials**; `fetch` appends them. Throttle: its own limiter (≥ 1.2 s between request starts, 1 thread until `ssuser.maxthreads` says more, clamped 1–6). 401/423 (API closed, temporary) pause; 430/431 (daily quota; also when `requeststoday ≥ maxrequestsperday`) are `SourceError::Exhausted` — source-wide: ScreenScraper is skipped for the rest of the run with one warning and the fill goes on with the other sources (a pause would repeat on every resume until the quota resets); 403/426 are a per-source refusal (`Auth`); 429 (too many threads) is retried by the polite client and then pauses. Dev credentials from `option_env!`; the user account (keychain) is optional and sent only when both user and password are stored (ES-DE, not Recalbox). The source is shown "not available in this build" otherwise. ScreenScraper system ids are added to `systems.toml` for the systems listed in Task 8 only; others are "not available on screenscraper".
- **CLI keys come from the environment** (the CLI has no keychain): `COVERLY_SGDB_KEY`, `COVERLY_SS_USER`, `COVERLY_SS_PASSWORD`; new flag `--sources libretro,steamgriddb` overrides the settings order; hidden `--steamgriddb-url`, `--screenscraper-url` for tests.
- **"Why this candidate"** is a `PickReason` on the plan item and on the chosen `CandidateView` (index 0) — not free text: the UI localises it.
- **Search by title** (drawer) asks every enabled source; results are deduped by `(source, url)` instead of `(source, name)` (SteamGridDB has several grids per name).
- Not built in M6: TheGamesDB (research §16.9 suggests it — later), ScreenScraper quota display in the UI (the "Test" result says ok/invalid only), SteamGridDB for screenshots/titles.

```rust
/// A secret value (API key, password). `Debug` never shows it and it has
/// no `Display` or `Serialize`, so it cannot reach a log, a journal or the
/// webview by accident; `expose` is the one way to read it.
#[derive(Clone, PartialEq, Eq)]
pub struct Secret(String);

impl Secret {
    pub fn new(value: impl Into<String>) -> Secret {
        Secret(value.into())
    }
    pub fn expose(&self) -> &str {
        &self.0
    }
}

impl std::fmt::Debug for Secret {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.write_str("Secret(***)")
    }
}
```

```rust
use crate::credentials::Secret;

/// A GET request: URL, optional conditional ETag, a body size cap, an
/// optional Bearer key (redacted in `Debug`) and whether a 403 pauses.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct HttpRequest {
    pub url: String,
    pub if_none_match: Option<String>,
    pub max_bytes: u64,
    /// Sent as `Authorization: Bearer …` (SteamGridDB).
    pub bearer: Option<Secret>,
    /// A 403 pauses the phase (libretro/GitHub rate limit, spec §10)
    /// unless an API source answers 403 for a bad key: then `false`.
    pub forbidden_pauses: bool,
}

impl HttpRequest {
    pub fn get(url: impl Into<String>) -> HttpRequest {
        HttpRequest {
            url: url.into(),
            if_none_match: None,
            max_bytes: DEFAULT_MAX_BYTES,
            bearer: None,
            forbidden_pauses: true,
        }
    }
    // max_bytes / if_none_match unchanged
    pub fn bearer(mut self, key: Secret) -> HttpRequest {
        self.bearer = Some(key);
        self
    }
    /// A 403 comes back as a response (the source decides what it means).
    pub fn forbidden_passes(mut self) -> HttpRequest {
        self.forbidden_pauses = false;
        self
    }
}
```

```rust
/// Why the first of a ranked list was picked over the second.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "why", rename_all = "kebab-case")]
pub enum PickReason {
    /// The only candidate.
    Only,
    /// It matches the ROM better (kind or score).
    BetterMatch,
    /// A release beats a beta/proto/demo/hack (D22).
    Release,
    /// More net SteamGridDB votes than the next one.
    Votes { score: i64, next: i64 },
    /// More listings, sources and regions agree on it (D9 b, D34).
    Consensus { count: u8, next: u8 },
    /// Earlier in the user's source order.
    SourceOrder { source: String },
    /// Earlier in the region order; `rom` = it is the ROM's own region.
    Region { rom: bool },
    /// It carries the preferred language (D28).
    Language,
    /// Equal on every rule: the first by name, so the result is stable.
    Tie,
    /// The user picked it (review queue, drawer).
    User,
}

/// Names the rule that put `first` before `second` in a ranking by
/// `kind` (followed by the D28 language tie-break).
pub fn explain(
    kind: StrategyKind,
    ctx: &RankContext,
    first: &Candidate,
    second: Option<&Candidate>,
    languages: &[String],
) -> PickReason {
    let Some(second) = second else { return PickReason::Only };
    if !is_unreleased_variant(&first.name) && is_unreleased_variant(&second.name) {
        return PickReason::Release;
    }
    let merge = kind == StrategyKind::Popularity;
    if !eligible(first, second, merge) {
        return PickReason::BetterMatch;
    }
    let by_source = || PickReason::SourceOrder { source: first.source.clone() };
    let src = |c: &Candidate| source_rank(c, ctx);
    match kind {
        StrategyKind::Popularity => {
            if vote_score(first) != vote_score(second) {
                return PickReason::Votes { score: vote_score(first), next: vote_score(second) };
            }
            if first.kind != second.kind {
                return PickReason::BetterMatch;
            }
            if first.consensus != second.consensus {
                return PickReason::Consensus { count: first.consensus, next: second.consensus };
            }
            if src(first) != src(second) {
                return by_source();
            }
            if region_rank(first, ctx, false) != region_rank(second, ctx, false) {
                return PickReason::Region { rom: false };
            }
        }
        StrategyKind::Priority => {
            if src(first) != src(second) {
                return by_source();
            }
            if region_rank(first, ctx, false) != region_rank(second, ctx, false) {
                return PickReason::Region { rom: false };
            }
        }
        StrategyKind::RomRegion => {
            if region_rank(first, ctx, true) != region_rank(second, ctx, true) {
                let rom = first.regions.iter().any(|r| ctx.rom_regions.contains(r));
                return PickReason::Region { rom };
            }
            if src(first) != src(second) {
                return by_source();
            }
        }
    }
    if language_rank(first, languages) != language_rank(second, languages) {
        return PickReason::Language;
    }
    if first.score != second.score {
        return PickReason::BetterMatch;
    }
    PickReason::Tie
}
```

```rust
use crate::identify::names::Region;

/// Merges the candidates every source offered for one ROM and media:
/// drops repeats of one image (same source and URL; the strongest kept),
/// adds cross-source agreement to `consensus` when `consensus` is on
/// (D34: another source with the same title in an overlapping region,
/// each source counted once), and sorts strongest first. `source` and
/// `origin` stay on each candidate.
pub fn merge_candidates(all: &mut Vec<Candidate>, consensus: bool) {
    sort_candidates(all);
    let mut seen = BTreeSet::new();
    all.retain(|c| seen.insert((c.source.clone(), c.url.clone())));
    if consensus {
        let info: Vec<(String, String, Vec<Region>)> = all
            .iter()
            .map(|c| (c.source.clone(), names::parse_name(&c.name, false).key, c.regions.clone()))
            .collect();
        for (i, c) in all.iter_mut().enumerate() {
            let (src, key, regions) = &info[i];
            if key.is_empty() || regions.is_empty() {
                continue;
            }
            let agreeing: BTreeSet<&str> = info
                .iter()
                .filter(|(s, k, r)| s != src && k == key && r.iter().any(|x| regions.contains(x)))
                .map(|(s, _, _)| s.as_str())
                .collect();
            let n = u8::try_from(agreeing.len()).unwrap_or(u8::MAX);
            c.consensus = c.consensus.saturating_add(n);
        }
    }
    sort_candidates(all);
}
```

```rust
//! Bearer key. Covers only: `/search/autocomplete/{title}` → game ids,
//! `/grids/game/{id}` (static, portrait 600x900 then 342x482, nsfw/humor/

//! hostile: parsed element by element, capped, image URLs only on

impl Grid {
    fn votes(&self) -> Votes {
        match (self.upvotes, self.downvotes, self.score) {
            (None, None, Some(s)) => Votes {
                up: u32::try_from(s.max(0)).unwrap_or(u32::MAX),
                down: u32::try_from((-s).max(0)).unwrap_or(u32::MAX),
            },
            (up, down, _) => Votes { up: up.unwrap_or(0), down: down.unwrap_or(0) },

pub struct SteamGridDbSource<'a> {
    http: &'a dyn Http,
    cache: &'a Cache,
    key: Option<Secret>,
    cfg: SgdbConfig,
}

fn bad(detail: impl Into<String>) -> SourceError {
    SourceError::BadResponse { source: SOURCE_ID.into(), detail: detail.into() }

impl<'a> SteamGridDbSource<'a> {
    pub fn new(http: &'a dyn Http, cache: &'a Cache, key: Option<Secret>, mut cfg: SgdbConfig) -> Self {
        cfg.base = cfg.base.trim_end_matches('/').to_string();
        SteamGridDbSource { http, cache, key, cfg }
    }

    /// The `data` list of an API answer (an empty list for a 404).
    fn get_data(&self, path: &str) -> Result<Vec<Value>, SourceError> {
        let key = self.key.clone().ok_or_else(|| SourceError::MissingKey { source: SOURCE_ID.into() })?;
        let url = format!("{}{path}", self.cfg.base);
        let req = HttpRequest::get(url.clone()).bearer(key).forbidden_passes().max_bytes(MAX_JSON_BYTES);
        let resp = self.http.get(&req)?;
        match resp.status {
            200..=299 => {
                let v: Value = serde_json::from_slice(&resp.body).map_err(|_| bad("not JSON"))?;
                if v.get("success").and_then(Value::as_bool) != Some(true) {
                    return Err(bad("the answer is not a success"));
                }
                match v.get("data") {
                    Some(Value::Array(a)) => Ok(a.clone()),
                    _ => Err(bad("no data list")),
                }
            }
            401 | 403 => Err(SourceError::Auth { source: SOURCE_ID.into(), status: resp.status }),
            404 => Ok(Vec::new()),
            status => Err(NetError::Status { status, url }.into()),
        }
    }

    fn cached<T: serde::de::DeserializeOwned>(&self, ns: &str, key: &str, ttl: i64) -> Option<T> {
        match self.cache.get_json::<T>(ns, key) {
            Ok(Some(s)) if now_unix() - s.fetched_at < ttl => Some(s.value),
            _ => None,
        }
    }

    fn search(&self, term: &str) -> Result<Vec<Game>, SourceError> {
        let key = term.to_lowercase();
        if let Some(g) = self.cached(NS_SEARCH, &key, self.cfg.search_ttl_secs) {
            return Ok(g);
        }
        let games: Vec<Game> = self
            .get_data(&search_path(term))?
            .into_iter()
            .filter_map(|v| serde_json::from_value::<Game>(v).ok())
            .filter_map(|g| Some(Game { name: clean_text(&g.name, MAX_NAME_CHARS)?, ..g }))
            .take(MAX_SEARCH_RESULTS)
            .collect();
        let _ = self.cache.put_json(NS_SEARCH, &key, &games, None);
        Ok(games)
    }

    fn grids(&self, game: u64) -> Result<Vec<Grid>, SourceError> {
        let key = game.to_string();
        if let Some(g) = self.cached(NS_GRIDS, &key, self.cfg.grids_ttl_secs) {
            return Ok(g);
        }
        let grids: Vec<Grid> = self
            .get_data(&grids_path(game, &self.cfg))?
            .into_iter()
            .filter_map(|v| serde_json::from_value::<Grid>(v).ok())
            .collect();
        let _ = self.cache.put_json(NS_GRIDS, &key, &grids, None);
        Ok(grids)
    }

    /// Image URLs only on steamgriddb.com over HTTPS. A base that is not
    /// HTTPS can only be a loopback mock (the client refuses anything else),
    /// so only then are images on the base's own host accepted (tests).
    fn allowed_image_url(&self, url: &str) -> bool {
        let host = host_of(url);
        let https = url.to_ascii_lowercase().starts_with("https://");
        let sgdb = host == "steamgriddb.com" || host.ends_with(".steamgriddb.com");
        let mock_base = !self.cfg.base.to_ascii_lowercase().starts_with("https://")
            && host == host_of(&self.cfg.base);
        !url.contains('@') && !host.is_empty() && ((https && sgdb) || mock_base)
    }

    fn grid_candidate(&self, game: &Game, g: &Grid, kind: MatchKind, score: u8) -> Option<Candidate> {
        let filtered = (g.nsfw && !self.cfg.nsfw) || (g.humor && !self.cfg.humor) || (g.epilepsy && !self.cfg.epilepsy);
        let image = matches!(g.mime.as_str(), "image/png" | "image/jpeg" | "image/webp");
        if filtered || !image || !self.allowed_image_url(&g.url) {
            return None;
        }
        let style = clean_text(&g.style, 32).unwrap_or_default();
        Some(Candidate {
            source: SOURCE_ID.into(),
            media: Media::Cover,
            name: game.name.clone(),
            url: g.url.clone(),
            fallback_url: None,
            regions: Vec::new(),
            kind,
            score,
            votes: Some(g.votes()),
            consensus: 0,
            origin: Some(format!("game {} · grid {} · {}x{} {style}", game.id, g.id, g.width, g.height).trim_end().to_string()),
        })
    }

    /// The games to take grids from, with how they matched.
    fn matched_games(&self, wanted: &ParsedName, games: &[Game], q: &ArtQuery) -> Vec<(Game, MatchKind, u8)> {
        let parsed: Vec<(Game, ParsedName)> = games.iter().map(|g| (g.clone(), parse_name(&g.name, false))).collect();
        let exact: Vec<&Game> = parsed.iter().filter(|(_, p)| p.key == wanted.key).map(|(g, _)| g).collect();
        match exact.len() {
            1 => vec![(exact[0].clone(), MatchKind::TitleExact, 95)],
            0 if q.fuzzy => {
                let mut scored: Vec<(u8, &Game)> = parsed
                    .iter()
                    .filter(|(_, p)| compatible(wanted, p))
                    .map(|(g, p)| (score(&wanted.key, &p.key), g))
                    .filter(|(s, _)| *s >= q.min_score)
                    .collect();
                scored.sort_by(|a, b| b.0.cmp(&a.0).then(a.1.id.cmp(&b.1.id)));
                scored.into_iter().take(MAX_GAMES).map(|(s, g)| (g.clone(), MatchKind::Fuzzy, s.min(94))).collect()
            }
            0 => Vec::new(),
            _ => exact.into_iter().take(MAX_GAMES).map(|g| (g.clone(), MatchKind::Fuzzy, AMBIGUOUS_SCORE)).collect(),
        }
    }
}

impl ArtSource for SteamGridDbSource<'_> {
    fn id(&self) -> &str {
        SOURCE_ID
    }

    fn candidates(&self, q: &ArtQuery) -> Result<Vec<Candidate>, SourceError> {
        if q.media != Media::Cover || !q.by_name {
            return Ok(Vec::new());
        }
        let wanted = match q.canonical {
            Some(c) => parse_name(c, false),
            None => q.rom.clone(),
        };
        if wanted.key.is_empty() || wanted.title.trim().is_empty() {
            return Ok(Vec::new());
        }
        let games = self.search(wanted.title.trim())?;
        let mut out = Vec::new();
        for (game, kind, score) in self.matched_games(&wanted, &games, q) {
            let mut grids = self.grids(game.id)?;
            grids.sort_by(|a, b| {
                b.votes().score().cmp(&a.votes().score())
                    .then(a.dimension_rank().cmp(&b.dimension_rank()))
                    .then(a.id.cmp(&b.id))
            });
            out.extend(
                grids.iter()
                    .filter_map(|g| self.grid_candidate(&game, g, kind, score))
                    .take(q.max_candidates.max(1)),
            );
        }
        sort_candidates(&mut out);
        Ok(out)
    }

    fn has_name(&self, _: &System, _: Media, _: &str) -> Result<bool, SourceError> {
        Ok(false)
    }

    /// The image from the CDN, without the key.
    fn fetch(&self, c: &Candidate) -> Result<Vec<u8>, SourceError> {
        if !self.allowed_image_url(&c.url) {
            return Err(SourceError::NotFound(c.url.clone()));
        }
        let r = self.http.get(&HttpRequest::get(c.url.clone()).max_bytes(MAX_IMAGE_BYTES))?;
        if (200..300).contains(&r.status) && !r.body.is_empty() {
            Ok(r.body)
        } else {
            Err(SourceError::NotFound(c.url.clone()))
        }
    }
}
```

```rust
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
struct SsGame { id: String, names: Vec<(String, String)>, medias: Vec<(String, String)> } // (region, text), (type, region)

fn text(v: &Value) -> Option<String> {
    match v { Value::String(s) => Some(s.clone()), Value::Number(n) => Some(n.to_string()), _ => None }
}
fn num(v: &Value) -> Option<u64> { text(v)?.trim().parse().ok() }

/// A game object, hostile-safe: digits-only id (≤ 12), region codes of 2–3
/// lowercase letters, known media types of parent `jeu` only.
fn parse_game(v: &Value) -> Option<SsGame> {
    let id = text(v.get("id")?)?;
    if id.is_empty() || id.len() > 12 || !id.bytes().all(|b| b.is_ascii_digit()) { return None; }
    let region_ok = |r: &str| (2..=3).contains(&r.len()) && r.bytes().all(|b| b.is_ascii_lowercase());
    let names = v.get("noms").and_then(Value::as_array).into_iter().flatten()
        .filter_map(|n| Some((text(n.get("region")?)?, clean_text(&text(n.get("text")?)?, 200)?)))
        .filter(|(r, _)| region_ok(r)).collect();
    let mut medias: Vec<(String, String)> = Vec::new();
    for m in v.get("medias").and_then(Value::as_array).into_iter().flatten() {
        let (Some(t), Some(r), Some(p)) = (m.get("type").and_then(text), m.get("region").and_then(text), m.get("parent").and_then(text)) else { continue };
        let entry = (t, r);
        if p == "jeu" && MEDIA_TYPES.contains(&entry.0.as_str()) && region_ok(&entry.1) && !medias.contains(&entry) {
            medias.push(entry);
        }
    }
    Some(SsGame { id, names, medias })
}
```

Methods (implement exactly these behaviours):

- `new`: trims the base's trailing `/`; `limiter = Limiter::new(1, cfg.min_interval)`.
- `threads(&self) -> usize`: current limiter `capacity()`.
- `fn creds(&self) -> String`: `devid=…&devpassword=…&softname=…&output=json` then `&ssid=…&sspassword=…` when `user` is set; every value through `QUERY_VALUE`.
- `fn api_url(&self, endpoint: &str, params: &[(&str, String)]) -> String`: `{base}/{endpoint}?{creds}` + `&k=v` for each param (encoded).
- `fn scrub(&self, s: &str) -> String`: replaces each of dev id, dev password, user, user password — raw and percent-encoded — by `***` (skip empty).
- `fn send(&self, url: &str, max: u64) -> Result<HttpResponse, SourceError>`:
  1. if `exhausted` → `Err(SourceError::Exhausted { source, status: 430 })` (no request);
  2. take a permit from the current limiter;
  3. `self.http.get(&HttpRequest::get(url).forbidden_passes().max_bytes(max))`, mapping errors: `NetError::Status { status, .. }` → `Status { status, url: <base>/… without query }`, `Offline(m)` → `Offline(self.scrub(&m))`, `Insecure(_)` → `Insecure(self.cfg.base.clone())`, others unchanged;
  4. status `401 | 423` → `RateLimited { host, status }` (pause: the API is closed for now); `430 | 431` → set `exhausted`, `SourceError::Exhausted { source, status }` (source-wide, never a pause); `403 | 426` → `SourceError::Auth { source, status }`; `400` → `BadResponse("request refused (HTTP 400)")`; `404` and 2xx → `Ok(resp)`; any other → `Net(Status { status, url: base })`.
- `fn read_json(&self, resp: &HttpResponse) -> Result<Option<Value>, SourceError>`: 404 → `None`; parse JSON (else `BadResponse("not JSON")`); then `note_user(&v["response"]["ssuser"])`: `maxthreads` → if it differs from `threads()`, replace the limiter with `Limiter::new(n.clamp(1, 6) as usize, cfg.min_interval)`; `requeststoday >= maxrequestsperday > 0` → `exhausted = true` (the answer in hand is still used; the next request returns `Exhausted` without being sent).
- `fn hash_params(file_name: &str, size: u64, h: &HashOutcome) -> Option<Vec<(&'static str, String)>>`: `Content(r)` → `romtype=rom, romnom, romtaille=r.full.size, crc, md5, sha1` (uppercase); `ZipEntry { crc32, size, inner_name }` → `romtype=rom, romnom=inner_name, romtaille=size, crc`; `TooLarge { .. } | NameOnly` → `None` (title search instead). Order: `romtype, romnom, romtaille, crc, md5, sha1` after `systemeid` (matches the test path).
- `fn game(&self, sid: u32, q: &ArtQuery) -> Result<Option<(SsGame, MatchKind, u8)>, SourceError>`: by hash (`jeuInfos.php`, `response.jeu`, `Canonical`/100) when `hash_params` gives some; else, when `q.by_name`, by title (`jeuRecherche.php` with `systemeid` then `recherche` = the canonical's or ROM's parsed title; the first game of `response.jeux` with a name whose parsed key equals the wanted key → `TitleExact`/95; none → `None`). Each answer cached under `NS_GAME` with key `"{sid}|{params…}"` (JSON of `Option<SsGame>`), fresh for `cfg.ttl_secs`.
- `candidates`: `system.screenscraper` missing → `SystemUnavailable`; then one candidate per `(type, region)` of `media_type(q.media, q.system.arcade)` whose region maps with `ss_region` (`ss`/unknown regions dropped): name = the game's name for that region, else `wor`, else `us`, else the first; url = `format!("{base}/mediaJeu.php?systemeid={sid}&jeuid={id}&media={}", enc(format!("{t}({r})")))`; `regions: vec![region]`; `origin: Some(format!("jeu {id}"))`; `sort_candidates`.

```rust
/// Every credential a fill may use, read once when the job starts (the
/// app: keychain; the CLI: environment). Workers never touch the keychain.

fn usable(v: Option<String>) -> Option<Secret> {
    let v = v?;
    let v = v.trim();
    (!v.is_empty() && v.chars().count() <= MAX_SECRET_CHARS && !v.chars().any(char::is_control)).then(|| Secret::new(v))
}

impl SourceKeys {
    pub fn from_store(store: &dyn CredentialStore) -> SourceKeys {
        let get = |k| usable(store.get(k).ok().flatten());
        SourceKeys::assemble(get(CredentialKey::SteamgriddbApiKey), get(CredentialKey::ScreenscraperUser), get(CredentialKey::ScreenscraperPassword))
    }

                (Some(user), Some(password)) => Some(UserCredentials { user, password }),
                _ => None,
```

```rust
            match self.by_id(id).filter(|_| usable) {
                Some(s) => on.push(s),
                None => warnings.push(match id.as_str() {
                    steamgriddb::SOURCE_ID => "steamgriddb: no API key stored; skipped".to_string(),
                    screenscraper::SOURCE_ID => "screenscraper: not available in this build; skipped".to_string(),
                    other => format!("{other}: unknown source; skipped"),
                }),
            }
        }
        (on, warnings)
    }
    pub fn all(&self) -> Vec<&dyn ArtSource> {
        ["libretro", steamgriddb::SOURCE_ID, screenscraper::SOURCE_ID].iter().filter_map(|id| self.by_id(id)).collect()
    }
}

                ScreenScraperSource::new(self.http, self.cache, dev, self.keys.screenscraper_user.clone(), cfg)

    }
```

```rust
//! Source availability and "Test key" (M6). Values never leave Rust: the
//! answers are presence flags and a `KeyCheck`.

use coverly_core::credentials::{CredentialKey, DevCredentials};
use coverly_core::net::{NetConfig, PoliteHttp, UreqHttp};
use coverly_core::settings::KNOWN_SOURCES;
use coverly_core::sources::screenscraper::{check_account, SsConfig};
use coverly_core::sources::{steamgriddb, KeyCheck};
use serde::Serialize;

use crate::error::IpcError;
use crate::state::AppState;

#[derive(Clone, Debug, PartialEq, Eq, Serialize)]
pub struct SourceInfoView {
    pub id: String,
    /// This build can use it (ScreenScraper needs developer credentials).
    pub built: bool,
    /// Credentials it needs before it can run.
    pub needs: Vec<CredentialKey>,
    /// Built and every needed credential stored.
    pub ready: bool,
}

impl AppState {
    pub fn sources_info(&self) -> Vec<SourceInfoView> {
        let status = self.credential_status();
        KNOWN_SOURCES
            .iter()
            .map(|&id| {
                let (built, needs) = match id {
                    "steamgriddb" => (true, vec![CredentialKey::SteamgriddbApiKey]),
                    "screenscraper" => (DevCredentials::from_build().is_some(), vec![]),
                    _ => (true, vec![]),
                };
                let ready = built && needs.iter().all(|k| status.set.get(k).copied().unwrap_or(false));
                SourceInfoView { id: id.to_string(), built, needs, ready }
            })
            .collect()
    }

    pub fn test_source_key(&self, source: &str) -> Result<KeyCheck, IpcError> {
        let cfg = self.fill_config();
        let net = NetConfig { retries: 0, ..cfg.net.clone() };
        let http = PoliteHttp::new(UreqHttp::new(&net), &net);
        let check = match source {
            "steamgriddb" => steamgriddb::check_key(&http, &cfg.endpoints.steamgriddb, cfg.keys.steamgriddb.as_ref()),
            "screenscraper" => match &cfg.keys.screenscraper_dev {
                None => KeyCheck::Unavailable,
                Some(dev) => {
                    let ss = SsConfig { base: cfg.endpoints.screenscraper.clone(), ..SsConfig::default() };
                    check_account(&http, &ss, dev, cfg.keys.screenscraper_user.as_ref())
                }
            },
            _ => return Err(IpcError::BadRequest(format!("no key to test for `{source}`"))),
        };
        log::info!("source key checked: {source} → {check:?}");
        Ok(check)
    }
}
```
