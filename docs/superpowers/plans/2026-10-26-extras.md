## Deviations from the spec (decided in this plan)

- **P-1: an Extras job's root is the library root.** Spec D10 says «carrying the game folder as `root`», but the no-Trash fallback (D8) moves files into `<library root>/.coverly-trash/<job>/…`, outside the game folder, and the `Writer` refuses targets outside its root. Extras jobs therefore `begin_with(library_root, data_dir, JobMeta { kind: Extras, source_root: None, .. })`, and `extras::ops` confines **every** target before calling the writer: `confine(game_extras_dir, target)` for files and folders, `confine(library_root/.coverly-trash/<job>, target)` for the fallback; anything else is `ExtrasError::OutsideExtras`. The game-folder level is only ever written to create `Extras/` itself.
- **P-2: a new `Op::CopiedIn { from, temp }` for adds.** Added files come from anywhere (picker, OS drop), outside the job's source root, and the organise undo of `Op::Copied` resolves `from` inside the source root (`undo_organize::source_path`), so it would refuse. `CopiedIn` is written twice like `Extracted`: the intent (no `fp`) before the copy streams into the job temp `.coverly-<job>-<n>.tmp` in the target folder, the completion (`fp` with the CRC computed while copying) after the no-clobber rename. Undo of a completion = the existing `undo_copy` (fingerprint check, kept and reported if changed); undo of a bare intent deletes the job temp only, never the target. `from` is informational and **never opened by undo**. Additive wire value: an older build sees `Op::Unknown` and refuses the whole job (D24). Recorded in the PR.
- **P-3: `extras.json` writes use `Writer::write` with `OverwritePolicy::Backup`.** That gives `Created` the first time and `Replaced { backup }` after (D3) with the existing atomic temp + rename. The malformed-file backup (D5) is `Writer::create_new_file` of the bad bytes under `extras.broken-<YYYYMMDD-HHMMSS>[-n].json` (journaled `Created`), then the fresh json.
- **P-4: the listing lives in core, the cache in Tauri.** `extras::index::list` is pure over the filesystem and returns a `Listing` with a content hash; Tauri's session keeps `(entry_id → Listing, rev)` and bumps `rev`. Handles are `(rev, index)`; a write re-lists and compares the files it names by `(path, size, mtime_ns)` before acting (D22).
- **P-5: drop tokens are tested without a window.** The `DragDrop` event handler is a thin adapter around `DropTokens::record(paths, position, now) -> DropEvent` and `DropTokens::take(token, now) -> Option<Vec<PathBuf>>`, unit-tested with injected time; the handler itself is checked in E2E/manual only (P-7).
- **P-6: the asset-protocol symlink-swap check decides the serving path in Task 17.** The task first writes the test «a granted path later swapped for a symlink pointing outside the library is refused». If the pinned Tauri passes it, media is served by `protocol-asset` with per-file grants; if not, the same task implements `coverly-media://` (lookup by `(generation, entry_id, rev, index)`, never a path) and the CSP uses that scheme instead of `asset:`. Either way the config test pins the final CSP string.
- **P-7: no Linux or Windows webview E2E.** WebKitGTK/WebView2 media codecs and drop coordinates are covered by unit tests and the fallbacks of D11/D12/D17; the PR lists them as not E2E-checked (spec §12.3).

/// A user category name: trimmed, NFC, refused (never rewritten) when it
/// would not be the same name on every system (D1).
pub fn validate_category_name(raw: &str, existing_user: &[String]) -> Result<String, NameRefusal> {
    let name: String = raw.trim().nfc().collect();
    if name.is_empty() { return Err(NameRefusal::Empty); }
    if name.chars().count() > MAX_CATEGORY_CHARS { return Err(NameRefusal::TooLong); }
    if name.starts_with('.') { return Err(NameRefusal::Dot); }
    if !portable(&name) { return Err(NameRefusal::NotPortable); }
    if name_key(&name) == EXTRAS_JSON || name_key(&name).starts_with("extras.broken-") { return Err(NameRefusal::Reserved); }
    let key = name_key(&name);
    if ExtrasCategory::from_dir_name(&name).is_some() || existing_user.iter().any(|u| name_key(u) == key) {
        return Err(NameRefusal::Taken);
    }
    Ok(name)
}

/// A new file name from a typed stem, keeping `ext` (D14).
pub fn validate_file_stem(dir: &Path, stem: &str, ext: &str) -> Result<String, NameRefusal> {
    let stem: String = stem.trim().nfc().collect();
    if stem.is_empty() { return Err(NameRefusal::Empty); }
    let name = if ext.is_empty() { stem } else { format!("{stem}.{ext}") };
    if name.len() > 255 { return Err(NameRefusal::TooLong); }
    if name.starts_with('.') { return Err(NameRefusal::Dot); }
    if !portable(&name) { return Err(NameRefusal::NotPortable); }
    if dir.join(&name).to_string_lossy().encode_utf16().count() > WINDOWS_MAX_PATH {
        return Err(NameRefusal::PathTooLong);
    }
    Ok(name)
}

pub fn normalize_tags(raw: &[String]) -> Result<Vec<String>, TagRefusal> {
    let mut out: Vec<String> = Vec::new();
    for t in raw {
        let t: String = t.trim().nfc().collect();
        if t.is_empty() { return Err(TagRefusal::Empty); }
        if t.chars().count() > MAX_TAG_CHARS { return Err(TagRefusal::TooLong); }
        if !out.iter().any(|o| o.to_lowercase() == t.to_lowercase()) { out.push(t); }
    }
    if out.len() > MAX_TAGS { return Err(TagRefusal::TooMany); }
    Ok(out)
}

```rust
#[derive(Debug, thiserror::Error)]
pub enum ExtrasError {
    #[error("extras.json is from a newer Coverly")] IndexNewer,
    #[error("the files changed since they were listed")] Changed,
    #[error("outside Extras/: {0}")] OutsideExtras(PathBuf),
    #[error("name refused: {0:?}")] Name(NameRefusal),
    #[error("tags refused: {0:?}")] Tags(TagRefusal),
    #[error("no Trash on this drive and no place to set it aside")] NoTrash,
    #[error("too many files or bytes for one action")] TooMany,
    #[error("not enough space: {short} bytes short")] NoSpace { short: u64 },
    #[error("a symlink is not followed: {0}")] Link(PathBuf),
    #[error("cancelled")] Cancelled,
    #[error(transparent)] Write(#[from] WriteError),
}

#[derive(Clone, Debug, PartialEq, Serialize)]
#[serde(tag = "kind", rename_all = "kebab-case")]
pub enum ExtrasNote {
    MalformedSaved { file: String },
    RenamedDup { name: String },
    Sanitised { names: Vec<String> },
    KeysSkipped { n: usize },
    HiddenSkipped { n: usize },
    SetAside { folder: String },
    StaysNoTrash { name: String },
    TrashFailed { name: String },
    Cancelled { copied: usize },
}

pub struct ExtrasCtx<'a> {
    pub library_root: &'a Path,
    pub game_dir: &'a Path,
    pub data_dir: &'a Path,
    pub trash: &'a dyn TrashBackend,
    pub now: SystemTime,          // injected for backup names and added_at
}

pub struct ExtrasOutcome { pub job: Option<String>, pub notes: Vec<ExtrasNote>, pub listing: Listing }

struct ExtrasJob<'a> { ctx: &'a ExtrasCtx<'a>, w: Writer, extras: PathBuf, file: ExtrasFile, malformed: Option<Vec<u8>>, notes: Vec<ExtrasNote> }
impl ExtrasJob<'_> {
    fn begin(ctx, listing: &Listing) -> Result<Self, ExtrasError>   // Newer → IndexNewer; re-list and compare (path,size,mtime) of every listed file → Changed
    fn confine(&self, target: &Path) -> Result<PathBuf, ExtrasError> // inside extras dir, or inside library_root/.coverly-trash/<job>
    fn ensure_extras_dir(&mut self) -> Result<(), ExtrasError>      // w.ensure_dir(extras) (DirCreated when new)
    fn write_index(&mut self) -> Result<(), ExtrasError>            // P-3: malformed bytes → create_new_file(extras.broken-…); then w.write(extras.json, serialize(&file), Backup)
    fn finish(self) -> Result<ExtrasOutcome, ExtrasError>           // w.finish(); list() again for the result
}
pub fn set_tags(ctx: &ExtrasCtx, listing: &Listing, file: usize, tags: &[String]) -> Result<ExtrasOutcome, ExtrasError>
pub fn forget(ctx: &ExtrasCtx, listing: &Listing, missing: usize) -> Result<ExtrasOutcome, ExtrasError>
```

The file model written is `listing.base` (salvaged/partial) with records replaced by the reconciled `files` + `missing` (D4), so `found` files get explicit records only on a write. `added_at` is RFC 3339 from `ctx.now` via the existing `time.rs` helpers.
