> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking. UI tasks (Group D) also REQUIRE frontend-design:frontend-design: follow `docs/08-brand/brand.md` and `design/tokens.json`, use the `src/components/ui` primitives and `SystemIcon`, and critique each changed screen with screenshots (UI gallery or mock backend) before committing.

**Goal:** The duplicates screen becomes readable at a glance and pleasant to work through with the keyboard. Each copy shows its region, revision, languages, release class and dump/modification marks as tags; its format, size, date, save and play facts; and, on the keeper, the rule that put it on the shelf. Each group shows its cover (library art first, then an already downloaded libretro-thumbnails image, offline only), with a clear missing slot, and a copy shows its own thumbnail when its art differs. Every copy and the `_Duplicados` folder can be shown in Finder / Explorer / the file manager, through the existing server-side scoped `reveal_path`. The game → kept copy → set-aside copies hierarchy and the conflict / report-only / other-version states are visible without reading. J/K, 1–9, ⌥⌘R / Shift+Alt+R and ⌘↩ / Ctrl+Enter work, and applying shows one calm illustrated set-aside scene. Nothing the planner decides or moves changes.

**Architecture:** Core (`coverly-core`) gains `dedupe::MemberFacts` on every `Member` (`#[serde(default)]`, skipped when empty, no plan version bump), filled in `Base::build_group` from the memoised `UnitFacts` (which now records art slots with sizes) plus a pure tag-merge function in the new `dedupe/facts.rs`. A new `dedupe/art.rs` resolves a group's or a member's art path from the plan alone and finds an already downloaded libretro image through an offline `Http`. Tauri gains one read-only command, `dedupe_art(plan_id, group, member, media)`, that returns bytes or `art-missing`. `reveal_path` becomes `async` and its known folders add the kept Organise plans. The capability file is unchanged. The frontend gets the new wire types, mock art and facts, a shared reveal label and reduced-motion hook, a generic object-URL cache entry, small pure helpers in `lib/dedupe.ts`, and the components `CopyFacts`, `GroupCover`, `RevealButton` and `SetAsideScene`, plus a new head and states for `DupGroup` and list-scoped keyboard handling in `DuplicatesScreen`.

**Tech Stack:** Rust 1.99 (edition 2021), serde, `insta`, `filetime`, `tempfile`; Tauri 2 with `tauri-plugin-opener` (already a dependency); React 19, TypeScript, Tailwind 3.4, zustand, Radix primitives in `src/components/ui`, Vitest + Testing Library; browser E2E with Chrome DevTools MCP on the Vite dev server with the mock backend.

## Deviations from the spec (decided in this plan)

- **DP-1: dev globals for the mock.** Spec §11 step 3 says the mock "exposes `revealedPaths` on the dev global used by the existing E2E". No such global exists: `createBackend` only sets `window.mockOrganizeTouch` and `window.mockDedupeScenario`. Task 9 adds `window.mockRevealedPaths()` and `window.mockDedupeArtCalls()` next to them (mock backend only, returning copies).
- **DP-2: no `LibretroSource` kept per plan.** `LibretroSource<'a>` borrows its `Http` and `Cache`, so it cannot live inside `StoredDedupe` without self-references. Instead `DedupeManager` memoises the **resolved** libretro URL per `(plan_id, group, media)` (`Option<String>`, also caching "none"), and a miss builds a `LibretroSource` over an offline `Http` for that call. The listing and index come from the SQLite cache, so a miss costs one index build for that system, and later groups of the same plan that hit the memo cost nothing. The memo is dropped with the plan.
- **DP-3: reveal in Organise goes through a prop.** `DupGroup` gains `onReveal?: (path: string) => void`. Without it, rows render no reveal button. `DuplicatesScreen` passes `dedupeStore.reveal`; `OrganizeScreen` passes a new `organizeStore.reveal(path)` that sets the store's `error` the way `dedupeStore.reveal` does.
- **DP-4: the copy's current place after apply** comes from `job.report.outcomes` (`status: 'quarantined'` → `to`; `'trashed'` → none), matched by `(group, member)`. Before apply and after undo it is `member.unit.primary`. This is `currentPath()` in `lib/dedupe.ts` (Task 11).
- **DP-5: `last_ns` is normalised in snapshots.** The `normalised()` helper of `crates/coverly-core/tests/dedupe_plan.rs` zeroes `mtime_ns` keys only. Task 4 also zeroes `last_ns`, so a save's mtime never makes the `library_plan` snapshot flaky on Windows or FAT.

```rust
pub fn tag_facts(catalogue: Option<&str>, stem: &str) -> MemberFacts {
    let file = parse_tags(stem);
    let cat = catalogue.map(|c| (c, parse_tags(c)));
    let (shown_name, shown, from) = match &cat {
        Some((c, t)) => (*c, t, TagSource::Catalogue),
        None => (stem, &file, TagSource::FileName),
    };
    let mut f = MemberFacts::default();
    f.regions = shown.regions.clone();
    f.revision = shown.revision_text.clone();
    f.class = (shown.class != ReleaseClass::Retail).then_some(shown.class);
    f.languages = languages(shown_name);
    // Unknown groups minus language lists ("En,Fr,De" is already in `languages`).
    f.other = shown.unknown_groups.iter()
        .filter(|g| languages(&format!("({g})")).is_empty())
        .cloned().collect();
    if !(f.regions.is_empty() && f.revision.is_none() && f.class.is_none()
         && f.languages.is_empty() && f.other.is_empty()) { f.tags_from = Some(from); }
    // Union of flags; source = first name that sets any flag.
    let cat_tags = cat.as_ref().map(|(_, t)| t);
    let cat_flags = cat_tags.map(|t| t.flags).unwrap_or_default();
    f.flags = DumpFlags {
        verified: cat_flags.verified || file.flags.verified,
        bad: cat_flags.bad || file.flags.bad,
        overdump: cat_flags.overdump || file.flags.overdump,
        alternate: cat_flags.alternate || file.flags.alternate,
    };
    f.flags_from = if !cat_flags.is_empty() { Some(TagSource::Catalogue) }
                   else if !file.flags.is_empty() { Some(TagSource::FileName) } else { None };
    let cat_mod = cat_tags.map(|t| t.modification).filter(|m| *m != ModClass::Original);
    let file_mod = Some(file.modification).filter(|m| *m != ModClass::Original);
    (f.modification, f.modification_from) = match (cat_mod, file_mod) {
        (Some(m), _) => (Some(m), Some(TagSource::Catalogue)),
        (None, Some(m)) => (Some(m), Some(TagSource::FileName)),
        _ => (None, None),
    };
    f
}
```
