## Deviations from the spec (decided in this plan)

- **D-1: `is_folder_per_game` is a free function.** Spec §5 names `SystemDb::is_folder_per_game(id)`. A `SystemDb` method would make `systems` depend on `organize::walk`, where the constant lives. Instead `organize::walk::is_folder_per_game(id: &str) -> bool` sits beside `FOLDER_PER_GAME_SYSTEMS`; the scan, dedupe and the planner call it. Same behaviour, no new dependency direction.
- **D-2: `pc_only` is optional in TypeScript.** Rust always serialises `pc_only` (and `contract.rs` pins it in the shared sample), but `SystemInfo.pc_only?: boolean` in `src/ipc/types.ts` (absent = false), like the mock fixture's `no_emulator?`. The 40-odd existing `SystemInfo` literals in tests stay valid; new code reads `s.pc_only === true`.
- **D-3: two mock picks.** Spec §10 describes one `?mockPick=pcarcade` holding a library, a card and a pile. The mock opens either a library or a pile per pick, so: `?mockPick=pcarcade` opens an ES-DE library with `type-x/` and `cave3rd/` shelves, and `?mockPick=pcarcade-pile` opens the pile (loose `mushisam.zip`, loose `Raiden IV (Type X)/`, `cave3rd/mushisam.zip`) organised with the Batocera layout.
- **D-4: one harness file.** Every new Rust check lives in `crates/coverly-core/tests/pc_arcade.rs` (created in Task 1, extended by later tasks) except the `names.rs` unit tests, the one-line extension of `dat.rs::mame_dat_still_maps_to_mame`, and the `screenscraper.rs` media-type assertion.
- **D-5: the ScreenScraper query for `typex` is by title.** Spec P11 says `romnom` = folder name. `hash_params` returns `None` for an unhashed entry, so the existing title search (`jeuRecherche`) runs with the cleaned title; no new parameter is added. Stated in the PR.

struct NoCloud;
impl MetaProbe for NoCloud {
    fn cloud_only(&self, _: &Path, _: &fs::Metadata) -> bool {
        false
    }
}

/// An empty file (parents created), mtime pinned to `n` seconds.
fn touch(path: &Path, n: u64) {
    fs::create_dir_all(path.parent().unwrap()).unwrap();
    fs::write(path, b"").unwrap();
    pin_mtime(path, n);
}

fn profile(id: &str) -> Profile {
    builtin_profiles()
        .into_iter()
        .find(|p| p.id == id)
        .unwrap_or_else(|| panic!("no profile {id}"))
}

fn name(path: &Path) -> String {
    path.file_name().unwrap().to_string_lossy().into_owned()
}

struct World {
    db: SystemDb,
    profiles: Vec<Profile>,
    cache: Cache,
}

impl World {
    fn new() -> World {
        World {
            db: SystemDb::builtin(),
            profiles: builtin_profiles(),
            cache: Cache::in_memory().unwrap(),
        }
    }
    fn env(&self) -> OrganizeEnv<'_> {
        OrganizeEnv {
            db: &self.db,
            profiles: &self.profiles,
            cache: &self.cache,
            dats: None,
            probe: &NoCloud,
            online: None,
            titles: None,
            now: SystemTime::now(),
        }
    }
    /// Seeds `dat` in the cache with `set`, one row per `(rom, bytes)`.
    fn cache_set(&self, dat: &str, set: &str, roms: &[(&str, &[u8])]) {
        let rows: Vec<DatRow> = roms
            .iter()
            .map(|(rom, bytes)| DatRow {
                game: set.into(),
                rom_name: (*rom).into(),
                size: Some(bytes.len() as u64),
                crc32: Some(format!("{:08X}", crc32fast::hash(bytes))),
                md5: None,
                sha1: None,
                serial: None,
            })
            .collect();
        self.cache.replace_dat(dat, &rows).unwrap();
    }
}

fn plan(world: &World, source: &Path, target: &Path, layout: &str) -> OrganizePlan {
    let opts = OrganizeOptions {
        layout: layout.into(),
        offline: true,
        target: Some(target.to_path_buf()),
        ..OrganizeOptions::default()
    };
    plan_organize(source, &opts, &world.env(), &|_| {}, &AtomicBool::new(false)).unwrap()
}

fn item_names(p: &OrganizePlan) -> Vec<String> {
