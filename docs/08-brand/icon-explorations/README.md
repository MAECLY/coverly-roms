# Icon explorations

How the Coverly ROMs icon was chosen. Each round is a self-contained page: open
its `index.html` in a browser (no server needed). Every candidate is kept with
its app icon, light and dark marks, and a `.json` with the idea behind it.

The shipping icon is not in these folders: its master files live in
[`design/icon/`](../../../design/icon/README.md).

## Round 1: ten concepts

[round-1/index.html](round-1/index.html)

Ten different ideas built to the brief in [`brand.md` section 9](../brand.md#9-icon),
all showing a solid cover next to a missing one:

| # | Name | # | Name |
|---|---|---|---|
| 01 | Half Mount | 06 | Muesca |
| 02 | Dog-ear | 07 | Fill Line |
| 03 | Shelfmark | 08 | Marcapáginas |
| 04 | Mordida | 09 | Last Corner |
| 05 | Cross Corner | **10** | **Shelf Gap** (picked) |

**Picked: #10 Shelf Gap**, a solid cover beside an empty slot on a shelf rule.

## Round 2: ten Shelf Gap variants

[round-2/index.html](round-2/index.html)

Ten refinements of Shelf Gap, each with a hand-tuned 16 px glyph:

| # | Name | # | Name |
|---|---|---|---|
| v01 | Even Shelf | v06 | Bound Cover |
| v02 | Gap First | v07 | Tagged Shelf |
| v03 | Open Slot | v08 | Paper Shelf |
| v04 | Full Shelf | v09 | Bold Gap |
| **v05** | **Lean-To** (picked) | v10 | Hollow Shelf |

**Picked: v05 Lean-To** (2026-10-17). The solid cover no longer overlaps the
empty slot: it leans about 12° against it, and both rest on the shelf rule. The
gesture of a book propped on a shelf makes the icon warmer, and keeping the two
shapes apart reads better in one colour and at 16 px.

The files in `round-2/v05-*` are the candidate as presented. The production
version in `design/icon/` adds a final polish pass (see its README).
