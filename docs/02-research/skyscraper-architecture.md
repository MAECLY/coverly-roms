Corrections:
(1) The list of extensions that make cacheId hash the filename has no m3u. The real list is uae, cue, conf, sh, svm, scummvm, mds, zip, 7z, gdi, ml, bat, au3, po, dsk and nib. QFileInfo::suffix() is compared case-sensitively.
(2) The libretro-thumbnails rule replaces &*/:`<>?\|" with '_'. Skyscraper's regex [&*/:\\\"<>?|] does not include the backtick, so it is not quite the full convention.
(3) The summary said 'ScreenScraper is the only module that identifies ROMs by hash'. That is not exact: ZXInfo (worldofspectrum) automatically searches by the SHA-512 of the file first. GameBase can match a CRC column, but only against the search string; it does not hash the file.
(4) The rule that raises a score of 50 or more to 100 when the title is contained only runs if the score is below minMatch.
(5) The searchStem rule only applies when the file's extension matches one of the searchStem patterns.
(6) romtaille is always the size of the archive on disk, even when the hashes come from the unpacked file.
(7) Only 91 of the 126 peas.json platforms have a retroarch_dbname.

I added these missing points:
- The rate limiter is per worker. Each thread builds its own scraper with its own QTimer, so total throughput is threads/interval.
- MATCH_ONE sources take the first result, with only a year check.
- regionFromFilename defaults to 'inline' and can be set to 'off'.
- Thumbnail files are named from the sanitized game title, not the ROM filename.

## Lessons for Coverly ROMs

- Use two phases. First, audit and gather every candidate cover per ROM into a local cache, with source and timestamp. Second, apply them to the output layout, resolving each cover by a per-type source priority with 'newest wins' as the fallback (Skyscraper's Cache::fillType).
- Use a content hash as the ROM's identity, but compare extensions case-insensitively. Skyscraper's case-sensitive suffix() check hashes '.ZIP' by its contents but '.zip' by its filename. Hash the filename for archives and multi-file formats (cue, gdi and also m3u, which Skyscraper misses) and for files over about 50 MiB. Keep a path+mtime quick-id index so a re-audit does not hash everything again.
- Compute CRC32, MD5 and SHA1 in one streaming pass. For a zip or 7z holding a single file, hash the inner file with a library (for example the zip's central-directory CRC32 needs no decompression) instead of shelling out to 7z. That lets Coverly look up exact No-Intro or Redump names before any fuzzy matching.
- libretro-thumbnails is matched by name. Copy the normalisation pipeline: strip brackets and rev/version suffixes, change '_' to a space, move ', The' to the front, swap numerals, and fall back to the name without its subtitle. Score with Levenshtein as 100*(L-d)/L, with a threshold of about 65 and a sequel-numeral guard. Compare on Unicode characters, not UTF-8 bytes as Skyscraper does.
- Use the complete libretro sanitisation set &*/:`<>?\|" -> '_'. Skyscraper leaves out the backtick, so titles containing one would miss their thumbnail. Name output files after the matched playlist or game title (as Skyscraper's RetroArch output does) or after the ROM name, depending on the frontend; make this a setting.
- Give regions a configurable priority list, with regionFromFilename 'inline' as the default, so a (USA) ROM prefers the USA box art. Map the short GoodTools codes (U), (E), (J), (JUE) as well as the No-Intro (USA, Europe) forms.
- Ship a platform table (folder name to aliases, extension globs and libretro db name) with a user-local override file. Expect gaps: 35 of Skyscraper's 126 platforms have no RetroArch db name, so Coverly needs a fallback and a way to edit the mapping in the UI.
- Rate limits are per worker in Skyscraper, so the total rate grows with the thread count. Coverly should use one global token bucket per source (and the raw.githubusercontent or thumbnails.libretro.com CDN should also be throttled politely). Add exponential timeouts, a minimum image size of 256 bytes or more, image decoding to validate each download, and a clean stop on 429 or quota responses.
- Show uncertain results instead of hiding them: keep a not-found and low-score report, an interactive candidate picker that marks the suggested choice, a manual query and a persistent alias map. In the GUI, add a 'review needed' filter next to 'has cover' and 'missing cover'.
- Support per-folder ignore markers (one for the folder only, one for the whole subtree) and include/exclude globs. Make sure the browser view and the audit apply them the same way; in Skyscraper they are ignored in cache mode.
