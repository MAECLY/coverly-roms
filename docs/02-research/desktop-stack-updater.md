## Summary

I re-checked every claim against fresh shallow clones in /private/tmp/claude-501/-Users-miguelangelesparzacalero-Documents-GitHub/35b7c020-f2ae-412f-b757-99c24a9a498b/scratchpad/research-clones/verify-updater: plugins-workspace, tauri-action, tauri-docs (last commit 2026-10-14), electron-builder and wails (master). I also checked live npm/crates.io and the GitHub API, and fetched the GitHub docs, the Wails docs and the Better Stack article.

Most of the dossier holds, and the Tauri 2 recommendation stands. Four claims needed fixing:

1. **Ubuntu ARM and billing.** "Only available in public repos" is about the `ubuntu-22.04-arm` matrix entry. The "invoiced for build minutes" warning is about the separate, much slower `pguyot/arm-runner-action` emulation workflow, not the official workflow.
2. **APPLE_SIGNING_IDENTITY.** It is not a secret in the macOS signing example. The workflow takes it from the imported keychain (`env.CERT_ID`, found by grepping for "Developer ID Application").
3. **Wails v3 releases.** The feed is at v3.0.0-beta.30 (2026-10-15), not beta.2. It is still prerelease, with roughly twice-weekly automated betas.
4. **Size benchmark.** The "Tech Insider 3.2 MB vs 85 MB" figure has no cited URL, so I could not verify it.

Facts the dossier was missing:
- **Fallback lookup.** The Tauri updater first looks for `{os}-{arch}-{installer}`, then falls back to plain `{os}-{arch}`.
- **Windows default is MSI.** `updaterJsonPreferNsis` defaults to `false`, so tauri-action puts MSI in the generic windows entry unless you set it to `true`. The generic linux entry always gets the AppImage.
- **Windows install mode.** Tauri's Windows `installMode` defaults to `"passive"`.
- **Upcoming config change.** `createUpdaterArtifacts` will be removed in v3.
- **Losing the private key.** Losing the updater private key blocks all future updates to existing installs.
- **Tauri v3 status.** v3.0.0-alpha.5 currently holds GitHub's "Latest" release flag. Stable 2.x is still what npm and crates.io serve by default (`latest` tag / `max_stable_version`).
- **Next Electron majors.** electron-builder 27 and electron-updater 7 are in alpha on npm's `next` tag.

## Lessons for Coverly ROMs

- Use Tauri 2 (tauri 2.12.x, @tauri-apps/plugin-updater 2.14.x, tauri-action@v1). Pin 2.x explicitly: v3.0.0-alpha.5 holds GitHub's 'Latest' release flag, though stable 2.x is still what npm and crates.io serve by default.
- In tauri.conf.json set bundle.createUpdaterArtifacts: true (not v1Compatible) and plugins.updater.pubkey. Point plugins.updater.endpoints at https://github.com/<owner>/<public-repo>/releases/latest/download/latest.json. On Windows keep installMode 'passive'.
- Generate the key once with `tauri signer generate`. Store TAURI_SIGNING_PRIVATE_KEY and its password as Actions secrets, and keep an offline backup, because a lost key means existing installs can never be updated again.
- Set updaterJsonPreferNsis: true in tauri-action. Its default is false, which points the generic windows-x86_64 entry at the MSI.
- On Linux the generic linux-x86_64 entry gets the AppImage. deb and rpm installs pick their own linux-x86_64-deb or linux-x86_64-rpm entries, which tauri-action writes too. The updater tries `{os}-{arch}-{bundle}` first and then falls back to `{os}-{arch}`.
- Publish releases from a PUBLIC repo, either the app repo itself or a separate coverly-releases repo. For the separate repo, use tauri-action's owner/repo inputs with a PAT secret as GITHUB_TOKEN plus releaseCommitish. Never ship a token in the app. latest.json URLs point at api.github.com asset endpoints, which need no token only when the repo is public.
- Public repos also get the free ubuntu-22.04-arm runner for Linux arm64 builds. In a private repo you would need the slow arm-runner-action emulation (about 1 hour per build), billed in minutes.
- For macOS notarization in CI, add secrets APPLE_CERTIFICATE (a base64 .p12), APPLE_CERTIFICATE_PASSWORD, APPLE_ID, APPLE_PASSWORD (app-specific password) and APPLE_TEAM_ID. Derive APPLE_SIGNING_IDENTITY from the keychain as the official example does. The free Apple account cannot notarize, so budget $99/yr.
- Windows signing can wait until later, but expect SmartScreen warnings either way: EV certificates no longer give instant reputation. Azure Artifact Signing works through Tauri's built-in support or signCommand.
- Keep the Electron fallback (electron-builder 26.15.x / electron-updater 6.8.x). Skip Wails v3 for now: it is still beta (beta.30) and its updater needs .zip bundles instead of dmg/pkg/msi.
