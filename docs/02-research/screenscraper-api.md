# ScreenScraper.fr API v2 as a secondary cover source, compared with TheGamesDB and SteamGridDB (verified)

> Generated from research workflow `wf_46f73971-0a2` (2026-10-15): one research agent + one skeptical verifier per topic. Claims: 27 verified, 8 corrected.

## Summary

I re-checked every claim against fresh copies of the primary sources on 2026-10-15. The sources were the ScreenScraper webapi2.php page (fetched and converted to text), the TGDB spec.yaml and key.php, the SGDB openapi.yml, and shallow clones of ES-DE, Recalbox ES and Skyscraper in /private/tmp/claude-501/-Users-miguelangelesparzacalero-Documents-GitHub/35b7c020-f2ae-412f-b757-99c24a9a498b/scratchpad/research-clones/verify-screenscraper-api.

**What holds up:** All the ScreenScraper doc claims are accurate word for word: the terms, dev credentials obtained through the forum, the betatest status, the parameters, the 400-with-path error, the 30-result search limit, CRCOK/MD5OK/NOMEDIA, the quota fields and the HTTP 400-431 codes. So are the SteamGridDB claims.

**Corrections:**
(1) The clients do not share one region fallback order. ES-DE uses region > wor > us > eu > jp > cus > first available for media, and region > wor > us > ss > eu > jp for names. Recalbox uses region > wor > us > jp > ss > first, with no 'eu' step.
(2) Recalbox does not hash the inner file of a zip. It computes MD5 over the whole file, and only when the file is under 20 MiB. Its CRC32 is never actually sent, because of a bug: the string is computed but never assigned. It also always appends ssid/sspassword, not only when the user has configured them.
(3) ES-DE does not send crc, sha1 or romtype to jeuInfos. It sends romnom, plus md5 and romtaille when it computed an MD5, plus systemeid for each mapped platform.
(4) Skyscraper sends its devid ('muldjord') in plaintext and obfuscates only the password with unMagic. It sends crc, md5, sha1, romnom and romtaille.
(5) TheGamesDB is not title-only. Its spec has /v1/Games/ByGameHash (md5/crc, with filter[platform]), and /v1/API/Limit checks the remaining allowance without counting against it.
(6) In ES-DE, 'steamgrid' and 'screenmarque' appear only in a comment. They are not string constants.

**Additions:** mediaJeu.php also takes systemeid. jeuInfos responses also carry a 'serveurs' block (CPU load, threadsmin, nbscrapeurs). maxthreads and maxdownloadspeed are returned even for unregistered users. Error 429 has four variants, including one for 'leecher' users. The full endpoint list also includes mediaVideoJeu, mediaManuelJeu, romTypesListe, infosJeuListe and the bot* endpoints.

## Lessons for Coverly ROMs

- Licensing gate stands (verified): the ScreenScraper API may only be used in fully free, distributed apps unless the team authorizes otherwise. Keep Coverly free and request devid/devpassword on the screenscraper.fr forum early.
- Make ScreenScraper opt-in, and follow ES-DE rather than Recalbox: append ssid/sspassword only when the user has entered both. Store them in the OS keychain. Show maxthreads, requeststoday/maxrequestsperday and requestskotoday/maxrequestskoperday from ssuserInfos.php. Because ssuser is sometimes missing from jeuInfos responses, re-poll ssuserInfos periodically.
- Do not hard-code one region order and claim it is 'what clients do'; the clients differ. ES-DE uses region>wor>us>eu>jp>cus>first, and Recalbox uses region>wor>us>jp>ss>first. Make the order a configurable list, defaulting to user region>wor>us>eu>jp>ss>cus>first available. Remember that video and fanart have no region.
- Hashing: the API wants at least one of crc/md5/sha1 plus romtaille. Send all three, as Skyscraper does, because the docs say 'le mieux serait les 3'. Use romtype rom/iso/dossier and the bare filename for romnom. Make the large-file hashing cutoff configurable; ES-DE exposes a MiB setting and Recalbox uses 20 MiB. Hash the file as stored. None of the reference clients hashes inside zips, so treat inner-zip hashing as an optional experiment, not established practice.
- Learn from Recalbox's bug, where the CRC is computed but never assigned: unit-test the outgoing URL builder so every hash Coverly computes actually reaches the query string.
- Throttle: at least 1.2 s between requests (Skyscraper, at ScreenScraper's request), 1 thread when anonymous, and at most ssuser.maxthreads otherwise. On 429, back off about 5 s and retry. Stop on 430/431. On 401/423, pause and show 'server saturated/closed'; the 'serveurs' block (serveurcpu, threadsmin) also allows proactive slow-down. On 426, prompt the user to update through the auto-updater.
- mediaJeu.php needs systemeid, jeuid and media 'type(region)'. Send the local cover's crc/md5/sha1 so the server can answer CRCOK/MD5OK/SHA1OK instead of re-sending the file. Use maxwidth/maxheight/outputformat to fetch cover-sized images.
- Cover type mapping: box-2D by default and flyer for arcade/MAME/FBA. Offer box-3D, mixrbv1/mixrbv2, ss/sstitle, wheel/wheel-hd, box-2D-back and support-2D as user-selectable alternatives.
- TheGamesDB is more useful than the dossier implied. /v1/Games/ByGameHash (md5/crc plus filter[platform]) supports exact matching. /v1/API/Limit checks the allowance for free. Images come from /v1/Games/Images?filter[type]=boxart and base_url.original + filename. The quota is small (about 1000/IP/month per Skyscraper, with a policy change on 2026-02-17), so require a user-supplied key and use TGDB only for gap-filling.
- SteamGridDB is confirmed as PC-storefront oriented (steam/egs/gog-like platforms, Steam-shaped grid sizes). Keep it as an optional source for PC titles only, using the user's own Bearer token.
